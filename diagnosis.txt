RMFOODFP 端口诊断报告
========================
日期: 2026-09-19

问题:
- 端口8000存在僵尸TCP连接 (PID 14680)
- 该进程已不存在，但TCP socket仍占用端口
- 这是Windows系统内核层面的问题

已尝试的方法:
1. ✓ taskkill /F /PID 14680 - 失败（进程已死）
2. ✓ net stop http / net start http - 失败
3. ✓ netsh http delete urlacl - 失败
4. ✓ Python ctypes TerminateProcess - 失败
5. ✓ Python socket connect + shutdown - 失败
6. ✓ Get-NetTCPConnection - 显示OwningProcess=14680

结论:
- 唯一解决方案: 重启系统
- 或等待Windows自动清理（可能需要几分钟到几小时）

当前状态:
- 端口8000: 被PID 14680占用（僵尸连接）
- 端口3000: 空闲
- Harness: 4个Node进程正常
