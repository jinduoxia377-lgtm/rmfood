# RMFOOD 移动端主题排版设计优化报告

**完成时间**: 2026-10-16
**依据规范**: 桌面端主题系统规范 `DESIGN.md v2.0`（Apple HIG / iOS 18）
**优化范围**: 微信小程序（miniprogram）全部主题系统文件 + 页面样式

---

## 一、差距分析结论

| 问题 | 现状（修复前） | 规范要求 | 影响 |
|:-----|:--------------|:---------|:-----|
| 深色模式用色错误 | GitHub 风格 `#0D1117`/`#161B22` | Apple 标准 `#1C1C1E`/`#2C2C2E`/`#3A3A3C` | 与桌面深色模式不一致 |
| 字号令牌错误 | `--font-size-body: 17rpx`（=8.5px） | 正文应为 28rpx（14px） | 卡片标题/正文过小 |
| 主文本色偏差 | `#000000` | `#1D1D1F`（桌面实际值） | 颜色不一致 |
| 品牌主色缺失 | 仅 `#007AFF` 系统蓝 | `#0066CC`/`#2997FF`（Action Blue） | 品牌识别不一致 |
| 间距非 8pt 网格 | 4/8/12/16/20rpx 散乱 | 8pt 网格（8px=16rpx） | 排版节奏不统一 |
| 圆角未对齐桌面 | 4/8/12/16rpx 散乱 | xs 8/sm 16/md 22/lg 36rpx | 组件形态不一致 |
| 乱码注释 | apple-ui/app-global 等 6+ 文件 GBK 乱码 | UTF-8 规范中文 | 代码可维护性差 |
| 页面硬编码色值 | 75 处 hex 色值 | 全部使用 CSS 变量 | 深色模式无法适配 |
| 全局动画文件未导入 | app-global.wxss 未引入 | 应作为全局样式导入 | 动画类失效 |

## 二、本次修改清单

### 核心主题系统文件（重写/深度优化）

| 文件 | 变更 |
|:-----|:-----|
| `design-tokens.wxss` | 对齐桌面规范：文本色 `#1D1D1F/#3A3A3C/#86868B/#AEAEB2`；品牌蓝 `#0066CC/#0071E3/#2997FF`；字号系统全面修正（body=28rpx）；间距 8pt 网格；圆角对齐；阴影对齐；新增语义文本色/Accent 色阶/别名令牌/`title-4`/`z-index-overlay`（令牌总数 153→171） |
| `typography.wxss` | 重建为 14 级排版刻度（hero-display → micro-legal），全部引用令牌，保留旧类名兼容 |
| `dark-mode.wxss` | 深色模式对齐 Apple HIG：`#1C1C1E/#2C2C2E/#3A3A3C`，文字用透明度层级，品牌蓝深色变体 `#2997FF`；自动+手动双通道一致 |
| `grid-system.wxss` | 卡片/列表/表单全部引用修正后令牌，圆角/间距规范化 |
| `layout-system.wxss` | 消除与 grid-system 的重复类冲突，统一布局与安全区 |
| `apple-ui.wxss` | 修复全部 GBK 乱码注释；主按钮/链接/导航/TabBar 选中态切换至品牌蓝；组件引用令牌 |
| `app-global.wxss` | 修复全部 GBK 乱码注释；补充无障碍减少动态适配 |
| `app.wxss` | 修复自身乱码；补导入 `app-global.wxss` |
| `theme.json` | 深色模式对齐 Apple HIG（`#1C1C1E/#2C2C2E`，TabBar 选中 `#2997FF`）；浅色 TabBar 选中 `#0066CC` |
| `app.json` | window 导航栏统一品牌绿 `#2D5A3D`；TabBar 色值与 theme.json 一致；selectedColor `#0066CC` |
