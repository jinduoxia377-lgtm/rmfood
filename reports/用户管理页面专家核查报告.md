## 六、第二轮深度修复（Playwright 浏览器全功能验证）

针对"更改角色不可用""用户详情缺更改密码"等问题，使用 Playwright 真实浏览器逐项验证，发现并修复了以下**前端运行时缺陷**：

### 6.1 页面崩溃（会导致后续所有操作失效）
- **问题**：操作日志面板渲染 `{log.details || log.action}`，当 `log.details` 为对象（后端审计日志返回 `{entity_type, resource_id}`）时，React 抛出 `Objects are not valid as a React child`，ErrorBoundary 接管后整个页面不可用。
- **修复**：`UserManagementPage.tsx` 改为 `{typeof log.details === 'string' ? log.details : log.action}`。

### 6.2 所有下拉框无法交互（Select 组件用错 API）
- **问题**：页面把 `<option>` 子元素传给 `@/components/ui` 的 Radix `Select`（其 API 应为 `SelectTrigger/SelectItem`），导致角色/状态/组织/每页数量/批量改角色/创建用户角色等下拉框**只渲染出孤立的 `<option>` 和隐藏 `<select>`，没有可点击控件**。
- **修复**：页面内新增本地原生 `<select>` 组件（支持 `<option>` 子元素），替换所有下拉框。

### 6.3 行复选框无法勾选（Checkbox 用错回调）
- **问题**：`Checkbox` 使用 `onChange`，而 UI 组件实际触发 `onCheckedChange`，导致勾选不生效、批量操作不可用。
- **修复**：全部改为 `onCheckedChange`。

### 6.4 批量启用的语义错误
- **问题**：批量启用/禁用均调用"切换状态"接口，导致"批量启用"实际把用户**反转为禁用**。
- **修复**：后端 `PUT /admin/users/{id}/status` 新增 `enable` 参数（强制启用/禁用）；前端新增 `setUserStatus(userId, active)`，批量操作按目标状态设置。

### 6.5 用户详情新增"更改密码"
- **后端**：新增 `POST /admin/users/{id}/reset-password`（管理员重置，留空自动生成临时密码，清除登录失败计数与锁定，写审计日志）。
- **前端**：用户详情-基本信息新增"更改密码"模块（输入新密码/随机生成/确认重置/显示临时密码），`admin.ts` 新增 `resetUserPassword`。

### 6.6 角色更改后详情弹窗不刷新
- **问题**：角色修改成功后详情弹窗仍显示旧角色。
- **修复**：`roleMutation.onSuccess` 同步更新 `detailUser` 状态。

## 八、第四轮开发（2FA 全流程打通 + 设置页修复 + 全功能回归）

### 8.1 登录页 2FA 动态码校验（打通全流程）
- **后端**：
  - `LoginRequest` 新增 `two_factor_code` 字段；

  - `/auth/login` 端点处理 `requires_2fa` 响应（不设置 Cookie）。
- **前端**：
  - `authApi.login` 将 `twoFactorCode` 映射为后端字段 `two_factor_code`；

  - `LoginPage` 新增 2FA 动态码输入步骤（6 位数字、返回重新输入密码、错误码提示）；
  - 修复"首次提交返回 2FA 后误导航到 dashboard"的时序缺陷（依据 store 返回值提前 return）。

### 8.2 设置页 2FA 自助管理修复
- **根因**：`hooks/useUserSettings.ts` 使用独立 `axios.create()` 且**未开启 `withCredentials`**，导致所有设置接口（2FA/设备/偏好）因不带 Cookie 而 401。

- **顺带增强**：`SettingsPage` 支持 `?tab=security` 深链（用 `useSearchParams` 初始化 Tab）。

### 8.3 其他修复
- 管理员为测试账号启用 2FA 时，`enable` 端点返回 `otpauth_url`（otpauth://totp/RMFOOD:user），前端详情页可复制密钥/链接。
- 清理所有测试数据，`dev-demo` 保持 `researcher` 角色、演示密码 `Demo@12345`。
