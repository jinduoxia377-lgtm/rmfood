## 四、🔴 lead 交叉审阅新发现：落地页存量 i18n bug（P1，独立于宣传页）

**已实测坐实**：`i18n/{zh-CN}/index.ts:46` 通过 `deepMerge` 把 `pages/landing.ts`（默认导出 `{ landing: {...} }`）合并进 `{ pages: ... }`，运行时真实键树是 **`pages.landing.*`**。但现有 `CTABanner / Pricing / FAQ` 组件及 `data/pricing.ts / faqs.ts` 全部用 **`t('landing.*')`**（缺 `pages.` 前缀），`i18n.ts` 无 `keyPrefix`、无自定义 `nsSeparator`、无局部 Provider 兜底。

**后果**：线上落地页 pricing / FAQ / CTA 的 i18n 取值**解析不到**（回落或显示键名）。这是存量缺陷，非本次宣传引入，但会直接破坏宣传页双语效果，建议单列修复。

**修复方向（二选一，04 §3.0 已给规则）**：
- 方案 A：批量把 landing 组件与 data 文件的 `t('landing.*')` / `*Key` 改为 `pages.landing.*`（与全站 `t('pages.dashboard.*')` 范式一致）；或
- 方案 B：把 landing 在 index.ts 改挂到根（脱离 `pages`），保持 `landing.*`。
推荐方案 A（对齐全站范式）。
