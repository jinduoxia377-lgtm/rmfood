## 第 3 章 场景二：H5 网页端（手机浏览器）

### 3.1 现状审计（Playwright 移动视口 375×812 实测 14 个路由）

**✅ 已有良好基础（无需大改）**

| 项 | 状态 | 证据 |
|:--|:--|:--|
| viewport | ✅ | `width=device-width, initial-scale=1.0, viewport-fit=cover` |
| 文档级横向溢出 | ✅ 0 | 全部页面 `scrollWidth == 375`（/ /dashboard /formulas /formulas/new /formulas/cases /databases /ai /experiments /organizations /settings /compliance /ingredients /billing） |
| 底部导航 + 安全区 | ✅ | `MobileBottomNav`（`fixed bottom-0`，`height:64px`，`--safe-area-inset-bottom`）；MainLayout 移动端 `paddingBottom: calc(64px + safe-area)` 防遮挡 |
| 移动侧边栏 | ✅ | MainLayout 移动抽屉 + AI 页移动汉堡菜单（`translate-x-full` 离屏） |
| 响应式工具库 | ✅ | `useMobile.ts`：断点（<768 / 768-1199 / ≥1200）、安全区、滑动手势、长按、捏合、`TouchButton/TouchCard/ResponsiveContainer/MobileBottomSheet/PullToRefresh` |
| 局部横向滚动容器 | ✅ | tabs（databases 9 个 tab 行、compliance tabs）、表格横向滚动、settings 色板行——均为常见移动模式 |

**❌ 需修复：触控目标尺寸不达标（Apple HIG ≥44px / WCAG 2.5.5）**

实测各页 <44px 目标（视口内）：

| 位置 | 实测高度 | 类型 | 建议修复 |
|:--|:--|:--|:--|
| `pages/.../organizations` 顶部 tab（概览/数据分析/我的组织/全部/回收站） | **36px** | 页面 tabs | `min-h-[44px]` 或改 `h-11` |
| `formulas/new` 功效标签（+增强免疫/+抗氧化/+降血压…） | **26px** | 胶囊 chip 按钮 | `min-h-[44px] px-3`（保持 text-xs 视觉，扩大热区） |
| `/ai` 功能导航项（智能对话/配方生成/安全检查…） | **40-41px** | 抽屉 nav 项 | `min-h-[44px]` |
| `/ai` 二级 tab（智能对话319/配方生成12…） | **32px** | 分段/胶囊 | `min-h-[44px]` |
| 快捷操作卡（新建配方/新建实验/AI 助手/数据库） | **38px** | 快速入口 | `min-h-[44px]` 或 `py-3` |
| `/billing` 返回组织列表 / 刷新 | **20px / 16px** | 内联文本按钮 | `inline-flex min-h-[44px] items-center` 或外包 `p-2` |

### 3.2 触控目标修复规范（统一规则）

新增/修改时遵循：

```css
/* 规则 T1：任何可点击元素的点击热区 ≥ 44×44px（88rpx） */
/* 视觉可小，热区必须大 —— 用 min-height + padding 扩热区，不要缩小字号 */
button, a[href], [role="button"] {
  min-height: 44px;             /* 全局兜底（移动端 media 内） */
}
/* 胶囊 chip：视觉 26px → 热区 44px */
.chip {
  min-height: 44px;
  padding: 0 16px;
  display: inline-flex;
  align-items: center;
}
/* 文本按钮：视觉紧凑，热区扩大 */
.text-link-btn {
  min-height: 44px;
  display: inline-flex;
  align-items: center;
  padding: 0 8px;
}
```

> 优先复用 `useMobile.ts` 的 `TouchButton` / `TouchCard` 组件；已用 Tailwind 的项目直接用 `min-h-[44px] inline-flex items-center`。

## 第 4 章 两类场景统一验收标准

### 4.1 自动化验收

| 维度 | 小程序端 | H5 网页端 |
|:--|:--|:--|
| 品牌色一致性 | `node miniprogram/scripts/mobile-audit.cjs` + `check-token-colors.cjs`：`--color-primary` = 桌面 `#047857`/`#34d399` | 运行时 CSS 变量比对：`--color-primary` 一致 |
| 无硬编码色 | `[1a]=0`（WXML 属性）`[1b]=0`（WXSS） | `ui-guard` 规则 + 主题门禁 `theme:gate` 全绿 |
| 字号令牌化 | `[5] 字号硬编码 = 0` | `theme:validate` 0 error / 基线 warn 不增 |
| 触控目标 | 主操作（导航/快捷入口/文本按钮）热区 ≥44px；次级 chip/tab ≥24px（WCAG AA 最低），24-43px 列入 P2 逐步提升 | 探针：<24px = 0（违规）；主操作 <44px = 0；24-43px 计数登记 P2 清单 |
| 横向溢出 | rpx 宽度 ≤750、无固定 px 宽 | 375px 视口 `scrollWidth == innerWidth` |
| 深色模式 | `token_colors.js` DARK 表 = `dark-mode.wxss` | 桌面 `theme:gate` GATE 深色项全绿 |
| 安全区 | `safe-top/safe-bottom` 覆盖全部页面 | `--safe-area-inset-*` + 底部导航留白 |

### 4.2 人工验收（真机）

| 检查项 | 小程序 | H5 |
|:--|:--|:--|
| iPhone X 以上深浅色切换无图标/文字脱节 | ✅ | ✅ |
| 底部安全区（Home Indicator）不遮挡 | ✅ | ✅ |
| 各页面无横向滑动（除 tabs/表格滚动区） | ✅ | ✅ |
| 主操作按钮热区 ≥44px（导航/快捷入口/提交/文本按钮） | ✅ | ✅ |
| 次级紧凑控件（chip/tab/分段）热区 ≥24px（WCAG AA 最低） | ✅ | ✅（约 90 处 24-43px 已登记 P2，后续逐步提升至 44px） |
| 大字体模式无截断 | ✅ | ✅（Web 跟随系统字体缩放） |
| 全功能链路走通（首页→列表→详情→操作） | ✅ | ✅ |
