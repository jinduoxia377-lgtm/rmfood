## 二、Phase 6: 预训练权重（优先级：高）

### 2.1 目标
从 TCMSP/DFBP 数据库加载真实药材数据，训练 PyTorch LSTM 生成器，提升生成质量。

### 2.2 任务分解

#### Task 6.1: TCMSP/DFBP 数据加载器
- **文件**: `app/services/ai/models/data_loader.py`
- **功能**:
  - 从数据库加载药材功效数据
  - 构建训练样本（配方序列 + 功效标签）

- **验证**: `tests/unit/test_data_loader.py`

#### Task 6.2: 训练脚本
- **文件**: `scripts/train_generator.py`
- **功能**:
  - 加载预训练数据
  - 训练 PyTorchGenerator
  - 保存模型权重
  - 训练日志记录
- **验证**: `python scripts/train_generator.py --epochs 100`

#### Task 6.3: 模型评估
- **文件**: `scripts/evaluate_generator.py`
- **功能**:
  - 计算生成配方的功效匹配度
  - 计算新颖性得分
  - 生成质量报告
- **验证**: 输出评估报告 JSON

## 六、Phase 10: 评估基准（优先级：中）

### 6.1 目标
建立量化评估体系，验证算法效果。

### 6.2 任务分解

#### Task 10.1: 交叉验证框架
- **文件**: `app/services/ai/models/cross_validation.py`
- **功能**:
  - 10-fold CV 实现
  - 分层抽样（按功效类别）
  - 结果聚合

#### Task 10.2: 评估指标
- **功效匹配度**: 生成配方功效 vs 目标功效相似度
- **新颖性得分**: 与现有市场配方的距离
- **多样性**: 生成配方的覆盖度
- **稳定性**: 多次运行结果方差

#### Task 10.3: 评估报告
- **文件**: `reports/algorithm_evaluation_report.md`
- **内容**:
  - 各指标对比（新引擎 vs 传统引擎）
  - AUC-ROC 曲线
  - 专家评分

### 6.3 评估公式
```python
# 功效匹配度
match_score = cosine_similarity(generated_effects, target_effects)

# 新颖性
novelty = 1 - jaccard_similarity(generated_herbs, market_herbs)

# 多样性
diversity = entropy(distribution_of_herb_pairs)
```
