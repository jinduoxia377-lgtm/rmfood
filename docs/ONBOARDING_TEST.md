## 🎯 核心操作路径（3步完成）

### 📍 步骤 1: 登录系统（30秒）

**操作流程**:
1. 打开浏览器访问 http://localhost:3001
2. 进入登录页面
3. 输入账号密码登录

**预期结果**:
- ✅ 登录页面加载时间 < 2秒
- ✅ 表单验证即时反馈
- ✅ 成功登录后跳转到仪表盘

**测试账号**:
| 角色 | 用户名 | 密码 |
|------|--------|------|
| 管理员 | `admin` | `Admin@123!` |
| 配方师 | `formulator` | `Formulator@123!` |

---

### 📍 步骤 2: 创建第一个配方（1分钟）

**操作流程**:
1. 在左侧导航栏找到 **"智能配方"** 菜单
2. 点击进入配方设计器
3. 选择 **"引导模式"**（推荐新手）
4. 选择功效目标（如：免疫调节）
5. 点击"下一步"完成成分推荐
6. 点击"导出报告"

**预期结果**:
- ✅ 导航清晰，核心功能入口明显
- ✅ 引导模式步骤清晰
- ✅ 系统自动推荐成分组合
- ✅ 成功生成配方报告

---

### 📍 步骤 3: 查看分析结果（30秒）

**操作流程**:
1. 查看配方分析结果页面
2. 查看协同效应指数
3. 查看安全性评估
4. 导出配方报告（PDF/Excel）

**预期结果**:
- ✅ 分析结果可视化展示清晰
- ✅ 关键指标一目了然
- ✅ 导出功能正常工作

## 🔧 测试环境准备

### 本地测试
```bash
# 启动后端
cd backend
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 启动前端
cd frontend
npm run dev
```

### 访问地址
- 前端: http://localhost:3001
- 后端API: http://localhost:8000
- API文档: http://localhost:8000/docs
