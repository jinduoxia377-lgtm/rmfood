## 二、已修复项

### P0（阻塞级，已全部修复）

**P0-1 删除「绝对安全」绝对化用语（广告法合规）**
- `default.yaml:90` → 「1. 【安全优先】所有建议必须严格遵守药食同源目录安全剂量范围，任何建议在出现不适时应立即停用并咨询医师」
- `chat_engine.py:43` 同步修改。

**P0-2 主对话路径接入 check_output() 安全过滤**
- 非流式 `/chat`：LLM 完成后调用 `check_output()`，不安全时用 `sanitized_text` 替换回答并记录 warning。
- 流式 `/chat/stream`：done 前对完整内容做 `check_output()`，不安全时追加「内容安全提示」补丁事件。
- 新增测试覆盖脱敏替换分支。

**P0-3 主对话路径剂量预校验**
- 新增 `_append_dosage_warnings()`：内置 60+ 种药食同源剂量表 + 正则提取「成分+克数」；
- 非流式返回前与流式 done 前调用，超标自动追加红色剂量警示（如「⚠️ 剂量警示：黄芪 50g 超出常规安全上限（9-30g），请遵医嘱并咨询医师」）；
- 检索/解析异常静默跳过，不阻断对话。
- 新增测试：正常剂量不追加 / 超标追加 / 范围剂量 / 未知成分跳过 / 空文本。
