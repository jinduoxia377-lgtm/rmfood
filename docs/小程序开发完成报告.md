### 3.2 健康评分色阶

```javascript
function getHealthScoreColor(score) {
  if (score >= 85) return '#4CAF50'  // A - 绿
  if (score >= 70) return '#8BC34A'  // B - 浅绿
  if (score >= 50) return '#FFC107'  // C - 黄
  if (score >= 30) return '#FF9800'  // D - 橙
  return '#F44336'                   // E - 红
}
```

### 3.3 请求封装

```javascript
class Request {
  async request(options) {
    // 1. 添加认证Token
    config.header['Authorization'] = `Bearer ${token}`
    
    // 2. 错误处理
    if (res.statusCode === 401) {
      app.handleTokenExpired()
    }
    
    // 3. 业务错误
    if (res.data.code !== 200) {
      this.handleBusinessError(res.data)
    }
  }
}
```

## 七、架构说明

### 7.1 六边形架构

```
┌─────────────────────────────────────────────────────────────┐
│                         小程序前端                           │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐       │
│  │  首页   │  │  AI对话 │  │ 配料分析 │  │  我的   │       │
│  └────┬────┘  └────┬────┘  └────┬────┘  └────┬────┘       │
│       └─────────────┼─────────────┼─────────────┘          │
│                     │           │                        │
│              ┌──────▼───────────▼──────┐                │
│              │      请求封装层          │                │
│              │  (Request + 拦截器)     │                │
│              └──────────┬──────────────┘                │
└─────────────────────────┼───────────────────────────────┘
                          │ HTTP
┌─────────────────────────▼───────────────────────────────┐
│                      FastAPI 后端                        │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐             │
│  │  AI服务  │  │ 营养服务 │  │ 电商服务 │             │
│  └──────────┘  └──────────┘  └──────────┘             │
└─────────────────────────────────────────────────────────┘
```

### 7.2 数据流

```
用户操作
    ↓
小程序页面
    ↓
Request封装（添加Token、错误处理）
    ↓
FastAPI后端
    ↓
业务逻辑处理
    ↓
返回JSON数据
    ↓
页面渲染更新
```
