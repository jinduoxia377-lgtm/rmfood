## 一、问题现象

用户在前端测试 RMCHM 数据源时，药材图片无法显示。

## 二、根因分析（三层问题）

### 2.1 问题链路

```
┌─────────────────────────────────────────────────────────────┐
│ 第1层：图片文件位置错误                                       │
├─────────────────────────────────────────────────────────────┤
│ 数据库 image_path 字段: "data/106FAM/八角.jpg"                │
│ 实际文件位置: D:\RMFOODFP\data\106FAM\八角.jpg                │
│ 静态服务挂载: /static → D:\RMFOODFP\backend\static\          │
│ 问题: 图片不在静态服务目录下                                    │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 第2层：前端路径拼接错误                                       │
├─────────────────────────────────────────────────────────────┤
│ 原始代码: src={`/${item.image_path}`}                        │
│ 生成URL: /data/106FAM/八角.jpg                               │
│ 正确URL: /static/data/106FAM/八角.jpg                        │
│ 问题: 缺少 /static 前缀                                       │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 第3层：后端路由未注册（已绕过）                                │
├─────────────────────────────────────────────────────────────┤
│ rmchm_images.py 模块未正确加载到 FastAPI                      │
│ 已采用直接静态文件访问方案绕过此问题                            │
```

## 三、解决方案

### 3.1 图片文件迁移

```powershell
# 创建静态目录
New-Item -ItemType Directory -Force -Path "D:\RMFOODFP\backend\static\data\106FAM"

# 复制图片文件
Copy-Item "D:\RMFOODFP\data\106FAM\*" "D:\RMFOODFP\backend\static\data\106FAM\" -Force
```

**结果**：107 张图片已复制到静态目录

### 3.2 前端代码修复

**文件**: `frontend/src/pages/database/tabs/HerbsTab.tsx`

```tsx
// 修复前（错误）
<img src={`/${item.image_path}`} alt={item.name_cn} />

// 修复后（正确）
<img src={`/static/${item.image_path}`} alt={item.name_cn} />
```
