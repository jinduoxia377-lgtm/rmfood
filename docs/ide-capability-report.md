## 四、智能开发工作流

### 4.1 日常开发流程

```
┌─────────────────────────────────────────────────────────────┐
│                    智能开发工作流                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 代码修改                                                │
│     └─ 编辑 .js / .wxss / .wxml 文件                        │
│                                                             │
│  2. 自动编译                                                │
│     └─ build-npm → 验证语法和依赖                           │
│                                                             │
│  3. 质量检查                                                │
│     └─ 静态分析 → 发现问题 → 自动修复                       │
│                                                             │
│  4. 预览验证                                                │
│     └─ preview → 生成二维码 → 扫码测试                      │
│                                                             │
│  5. 上传发布（需要GUI确认）                                 │
│     └─ upload → 提交审核                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 自动化脚本示例

```powershell
# 一键编译+预览
```
