# ADR-030: 组织管理页面功能补全

> Architecture Decision Record — 组织管理页面核心功能补全决策

## 背景

在完成了 UI/UX 一致性和高级功能开发后，发现组织管理页面存在多个核心功能缺失，导致页面无法正常使用：
1. 组织详情页路由未注册
2. 创建组织按钮不打开向导
3. 导航到详情页无实际路由跳转
4. 删除/归档操作仅刷新页面未调用 API
5. 批量操作为占位符

## 决策

### 1. 路由注册

**方案**：在 `App.tsx` 注册 `/organizations/:id` 路由

```tsx
const OrganizationDetailPage = lazyWithPreload(() => import('@/pages/organizations/components/OrganizationDetail'))

// 路由
{
  path: 'organizations/:id',
  element: (
    <Suspense fallback={<LoadingComponent />}>
      <OrganizationDetailPage />
    </Suspense>
  ),
}
```

**理由**：`OrganizationDetail` 组件已完整实现（6个Tab、成员/团队CRUD、设置），但缺少路由入口。

### 2. 创建组织向导集成

**方案**：主页面接入 `CreateOrgWizard` 组件

```tsx
const [showCreateWizard, setShowCreateWizard] = useState(false)

<Button onClick={() => setShowCreateWizard(true)}>创建组织</Button>

<CreateOrgWizard
  open={showCreateWizard}
  onClose={() => setShowCreateWizard(false)}
  onCreate={async (data) => { await createOrganization(data); setShowCreateWizard(false) }}
/>
```

**理由**：`CreateOrgWizard` 已实现4步流程（基本信息→详情→成员→确认），但主页面调用硬编码创建空组织。

### 3. 导航修复

**方案**：`onNavigateToDetail` 改为真实路由跳转

```tsx
onNavigateToDetail={(id) => {
  const org = organizations.find(o => o.id === Number(id))
  if (org) {
    addRecent(org.id, org.name, org.slug)
    navigate(`/organizations/${id}`)
  }
}}
```

同时添加 `searchInputRef` 修复快捷键搜索聚焦。

### 4. 删除/归档 API 调用

**方案**：`OrganizationDetail.tsx` 的 `handleDelete`/`handleArchive` 调用真实 API

```tsx
// 归档
await api.patch(`/organizations/${orgId}/archive`, { isActive: false })
navigate('/organizations')

// 删除
await api.delete(`/organizations/${orgId}`)
navigate('/organizations')
```

### 5. 数据修复

| 问题 | 修复 |
|------|------|
| `teamCount: 0` 硬编码 | 改为 `org.teamCount` |
| `loading={false}` 硬编码 | 改为 `loading={loading}` |
| 搜索框缺 ID | 添加 `id="org-search-input"` + `ref={searchInputRef}` |
| Emoji 图标 | 替换为 Lucide 图标（⚠️→AlertCircle/AlertTriangle，🗑️→Trash2） |

### 6. CreateOrgWizard 语法修复

**问题**：details 步骤中存在重复的 `<div>` 包裹和重复 label，导致 JSX 解析失败（500错误）。

**修复**：移除多余的 `<div>` 和 `<label>` 包装层。

## 修改文件清单

| 文件 | 变更内容 |
|------|----------|
| `src/App.tsx` | 新增 OrganizationDetailPage 懒加载 + `/organizations/:id` 路由 |
| `src/pages/organizations/OrganizationsPage.tsx` | 接入 CreateOrgWizard、修复导航、修复 loading/teamCount、添加 searchInputRef |
| `src/pages/organizations/components/OrganizationDetail.tsx` | 实现删除/归档 API 调用、替换 emoji 为图标、添加 api 导入 |
| `src/pages/organizations/components/CreateOrgWizard.tsx` | 修复重复 div 导致的语法错误 |
| `src/pages/organizations/components/BulkOperationsPanel.tsx` | 替换 emoji 为 Lucide 图标 |

## 影响评估

| 维度 | 影响 |
|------|------|
| 用户体验 | 核心功能（创建、导航、删除、归档）现在可正常工作 |
| 性能 | 无显著影响 |
| 兼容性 | 向后兼容，新增路由不影响现有功能 |
| 后端依赖 | 删除/归档/邀请成员等 API 依赖后端接口就绪 |

## 后续优化方向

1. **后端 API 补齐** — 归档、永久删除、克隆等接口需后端确认
2. **WebSocket 实时通知** — 组织活动实时推送
3. **虚拟滚动** — 组织数量超过 500 时引入
4. **组织模板** — 预置常用组织模板
