## 问题深度分析

### 结构性问题
1. **操作栏结构断裂**：标题、总用量、按钮分属三个独立 div，堆叠在 `space-y-5` 中导致垂直间距过大，视觉上缺乏操作区域的紧凑感
2. **添加成分弹窗**：搜索下拉列表为普通流元素，无绝对定位，展开时挤压下方表单字段

### 视觉一致性问题
3. **表格单元格 padding 不统一**：序号/名称列使用 `px-4 py-3`，但药食同源列和操作列仍为旧的 `p-3`
4. **统计摘要卡片**：无图标，视觉层次平淡，与 DashboardPage 风格差距明显
5. **总用量展示**：独立一行文字标签，不如整合进操作栏右侧的 rounded pill 样式
6. **展开详情行**：原为裸文本 `-`，无卡片包裹，视觉混乱

### 交互细节问题
7. **搜索下拉无 margin**：展开时紧贴 input 下方，无呼吸感
8. **搜索下拉无背景色/阴影**：透明背景导致与页面内容重叠时视觉不清

## 实施的修复

| Fix | 内容 |
|-----|------|
| A | **操作栏重构**：单行 `flex items-start justify-between`，左侧标题+分隔条，右侧总量pill+按钮，与DashboardPage compact action bar一致 |
| B | **表格单元格padding统一**：药食同源列和操作列 `p-3` → `px-4 py-3` |
| C | **搜索下拉绝对定位**：外层包裹 `relative` div，下拉列表 `absolute z-10 shadow-lg bg-white dark:bg-neutral-900`，避免挤压表单 |
| D | **统计摘要卡片升级**：每个卡片增加图标（BarChart3/Leaf/FlaskConical）、更大字号 `text-2xl`、白色背景 `bg-white dark:bg-neutral-900/50` |
| E | **图标导入修正**：补充 `FlaskConical` 到 lucide-react 导入 |
