## 目标

将 `http://localhost:3000/formulas/:id` 从骨架页面升级为功能完整的产品级详情页。

## 已完成开发内容

### 1. 成分详情数据真实化

新增 `ingredientDetails` useMemo，内置10味常用药材的完整数据（性味、归经、化学成分、药理作用、注意事项）：

| 药材 | 性味 | 归经 | 主要功效 |
|:-----|:-----|:-----|:---------|
| 枸杞 | 平·甘 | 肝、肾经 | 免疫调节、抗氧化 |
| 山药 | 平·甘 | 脾、肺、肾经 | 健脾益胃、降血糖 |
| 黄芪 | 微温·甘 | 肺、脾经 | 补气固表、利尿 |
| 党参 | 平·甘 | 脾、肺经 | 补中益气、健脾 |
| 当归 | 温·甘辛 | 肝、心、脾经 | 补血活血、调经 |
| 川芎 | 温·辛 | 肝、胆、心包经 | 活血行气、祛风止痛 |
| 白术 | 温·苦甘 | 脾、胃经 | 健脾益气、燥湿利水 |
| 甘草 | 平·甘 | 心、肺、脾、胃经 | 补脾益气、清热解毒 |
| 茯苓 | 平·甘淡 | 心、脾、肾经 | 利水渗湿、健脾宁心 |
| 红枣 | 温·甘 | 脾、胃经 | 补中益气、养血安神 |

成分展开详情表格从占位符 `-` 升级为真实数据，使用语义化颜色 token（`text-text-disabled` / `text-text-secondary`）。

### 2. 相关推荐 API 接入

- `loadRecommendations` 从动态 import 改为直接使用已导入的 `formulaApi.recommendations()`
- 新增 `based_on_formula_id: formula.id` 参数，提升推荐精准度
- 错误处理优化：`console.error` 日志 + toast 类型从 `error` 改为 `warning`
- 依赖数组更新为 `[formula?.id, formula?.targetEffects, addToast]`
- 推荐卡片区域新增说明文字

### 3. 分析历史记录

- 分析 Tab 新增"分析历史"小面板，展示最近3条分析记录
- 每条记录展示：类型标签 + 摘要 + 时间戳
- 使用已有的 `analysisHistory` useState 状态变量

### 4. 版本回滚

原代码已实现（L1910-1939），调用 `formulaApi.rollbackToVersion()`，无需修改。
