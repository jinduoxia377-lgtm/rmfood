# ADR-009: 前端架构与状态管理策略

## 状态
OK 已接受 (2026-06-15)

## 上下文

RMFOOD 前端 (923+ TSX/TS 文件) 需要统一的架构策略:
1. 组件组织: 90+ 页面组件
2. 状态管理: Zustand + React Query
3. 样式: TailwindCSS 4 + CSS 变量
4. 构建: Vite 8 + TypeScript

## 决策

- 前端架构分层: api/, components/, core/, hooks/, pages/, stores/, utils/, config/
- 状态管理: Zustand (客户端) + React Query (服务器)
- API 统一: frontend/src/api/client.ts
- 错误处理: ErrorBoundary + toast
- 国际化: frontend/src/i18n/
