# ADR-034: 配方详情页成分列表Tab UI修复

> 针对 `成分列表` Tab 的结构性错误和视觉细节进行修复

| # | 标题 | 状态 | 日期 | 领域 |
|:-:|:-----|:----:|:----:|:-----|
| 034 | [配方详情页成分列表Tab UI修复](./ADR-034-配方详情页成分列表Tab UI修复.md) | ✅ 已执行 | 2026-08-28 | 前端/产品化 |

## 发现的问题

### 结构性错误
1. **JSX闭合标签错误**：`</div>` 过早关闭了 `space-y-5` 外层容器（line 1850），导致 TabsContent 无法正确闭合
2. **Fix 7 残留多余标签**：插入 CompositionChart 卡片包裹时遗留了多余的 `</div>`

### 视觉问题
3. 操作栏使用了 `<h2>` 标签，与 DashboardPage 风格不一致
4. 添加成分弹窗缺少 section 分隔条
5. 成分表格缺少表头背景色、count 徽章
6. 展开详情行显示纯 `-` 无卡片包裹，视觉杂乱
7. 空状态过于简陋，缺少引导文案
8. 成分分布图表未包装在卡片中
9. 搜索下拉列表缺少分隔线

## 实施的修复

| 修复 | 内容 |
|------|------|
| 结构修复 | 删除 line 1850 过早关闭的 `</div>` |
| 标题样式 | `<h2>` → `<span>` + 绿色竖线分隔条 (`w-1 h-5 bg-secondary-500`) |
| 操作栏 | 总用量与按钮分离到独立行 |
| 添加成分 | 头部增加竖向分隔条，label 改为 `uppercase tracking-wider` |
| 表格表头 | 增加 `bg-neutral-50/50 dark:bg-neutral-900/30` 背景色 |
| 表格计数 | 表头增加 `{ingredientList.length} 项` 徽章 |
| 展开行 | 4个信息块改为 `rounded-lg border bg-white` 卡片样式 |
| 空状态 | 增加 `rounded-xl border` 包裹 + 引导文案 |
| 图表容器 | 用 `rounded-xl border p-4` 包裹，增加 `成分分布` 标签 |
| 搜索下拉 | 增加 `divide-y` 分隔线 |

## 验证结果

- TypeScript 编译：零错误 ✅
- 页面加载：`/formulas/14` → 200 OK ✅
