## 现状分析

`/formulas/:id` 页面目前拥有完整骨架（9个 Tab + 评论区 + 活动线 + 关联实验），但核心模块大部分为骨架或空数据。

### 各 Tab 深度评估

| Tab | 当前状态 | 缺失深度 | 优先级 |
|:----|:---------|:---------|:------:|
| 基本信息 | ✅ 内联编辑 | 标签管理、分类下拉、功效搜索 | P2 |
| 成分列表 | ⚠️ 表格存在 | 成分详情API缺失、搜索/排序 | P1 |
| 制作步骤 | ✅ 时间线 | 步骤编辑、拖拽排序 | P2 |
| 版本历史 | ⚠️ 列表存在 | 回滚功能、可视化Diff | P1 |
| 相关推荐 | ❌ 无数据 | API接入、智能排序 | P1 |
| 可解释性 | ⚠️ 组件挂载 | ComplianceAPI、报告生成 | P2 |
| 深度分析 | ✅ 6类分析 | 风味雷达图、效果曲线、保存历史 | P1 |
| 营养成分 | ✅ 标签+图表 | NRV趋势、同类对比 | P2 |
| 评论区 | ✅ 基础功能 | 楼层引用、表情、富文本 | P3 |
| 活动时间线 | ✅ 渲染 | 实际数据接入 | P2 |
| 关联实验 | ⚠️ 列表存在 | 实验状态可视化 | P3 |

## 开发计划

### Phase 1 — 核心数据填充（P1 优先级）

#### 1.1 成分详情真实化
- 接入后端药材 API，填充 性味归经 / 化学成分 / 药理作用 / 注意事项
- 成分表添加搜索/排序/过滤

#### 1.2 相关推荐 API 接入
- 调用 `formulaApi.getAIRecommendations()` 获取真实推荐
- 添加推荐评分排序和筛选

#### 1.3 版本回滚功能
- 实现 `formulaApi.rollbackToVersion()` 调用
- 添加回滚确认 Modal
- 版本 Diff 可视化增强

#### 1.4 深度分析图表丰富
- 风味预测 → 雷达图（TasteRadarChart）
- 效果预测 → 曲线图（EffectCurveChart）
- 稳定性预测 → 趋势图（StabilityTrendChart）
- 保存分析历史 → 侧栏展示

### Phase 2 — 交互增强（P2 优先级）

#### 2.1 基本信息增强
- 标签管理：输入后回车添加，点击删除
- 分类下拉：从后端分类树选择
- 功效 Tag 多选

#### 2.2 活动时间线真实化
- 使用后端真实 activity 数据
- 按类型筛选
- 点击展开详情

#### 2.3 营养成分增强
- NRV 环形图交互化
- 添加同类配方营养对比

#### 2.4 可解释性增强
- 合规检查数据真实化
- 报告导出 PDF/HTML

### Phase 3 — 体验优化（P3 优先级）

#### 3.1 UI 视觉统一
- 所有文字颜色语义化
- 卡片阴影、边框色统一
- 响应式断点优化

#### 3.2 性能优化
- 懒加载重型 Tab
- 虚拟列表（成分超过50条时）
- 接口请求缓存
