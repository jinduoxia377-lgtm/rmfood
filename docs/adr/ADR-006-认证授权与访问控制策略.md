# ADR-006: 认证授权与访问控制策略

## 状态
✅ 已接受 (2026-06-15)

## 上下文

RMFOOD 平台是多租户 SaaS 应用，需要处理:
1. 用户认证 (注册/登录/登出)
2. 角色权限控制 (管理员/配方师/研究员/审核员/只读)
3. 多租户数据隔离
4. API 密钥管理 (第三方集成)
5. OAuth2 SSO (企业客户)

## 决策

### 采用 JWT + OAuth2 Password Flow

- Access Token: 15 分钟有效期, RS256 签名
- Refresh Token: 7 天有效期, HTTP-only Cookie
- 密码: bcrypt (cost=12)
- 登录失败: 5次锁定30分钟

### 权限模型: RBAC + ABAC 混合

| 层级 | 控制范围 | 实现方式 |
|:-----|:---------|:---------|
| 租户级 | 租户隔离 | 中间件注入 tenant_id |
| 角色级 | 功能访问 | RBAC (角色-权限映射) |
| 资源级 | 数据权限 | ABAC (基于属性的条件) |
| 字段级 | 敏感字段脱敏 | 响应拦截器 |

### 核心模块

```
backend/app/services/auth/
├── jwt_manager.py      # JWT 签发/验证/刷新
├── oauth2_provider.py  # OAuth2 提供者
├── permission_engine.py # RBAC+ABAC 权限引擎
├── api_key_manager.py  # API 密钥管理
└── sso_connector.py    # SSO 连接器 (企业客户)
```
