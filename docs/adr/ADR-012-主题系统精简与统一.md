# ADR-012 — 主题系统精简与统一

**状态：** ✅ 已接受  
**日期：** 2026-08-15  
**领域：** 前端 / UI/UX  
**相关 ADR：** ADR-009（前端架构与状态管理）

---

## 背景

RMFOOD 前端主题系统在历史演进中积累了6套主题定义、双轨持久化存储、废弃的兼容层以及未桥接的设计 Token。本次重构对主题系统进行全面精简与统一。

## 决策

1. **预设主题收敛为2套**：仅保留 `light-default`（Apple HIG 翡翠绿）和 `dark-default`（Apple OLED 分层灰度），所有辅助功能模式（高对比度/阅读/色盲）改为运行时派生。
2. **淘汰旧版 `ThemeStyles` 双轨**：删除 `utils/theme/ThemeStorageAdapter.ts` 和 `utils/theme/VersionController.ts`，统一使用 `theme.storage.ts` 的 `UserCustomTheme` CRUD + 版本历史。
3. **统一导入路径**：所有组件从 `@/theme` 单一入口导入，不再直接引用 `@/stores/ThemeProvider` 或 `@/hooks/useTheme`。
4. **补全 Tailwind @theme**：在 `index.css` 中添加排版 Token（`--text-display-lg`、`--text-headline-lg` 等），桥接 `design-tokens.ts` 定义与 Tailwind 类名。

## 结果

- **TypeScript 编译：0 错误**
- **净减约 300+ 行死代码**，新增约 100 行有效代码
- **无残留引用**：`@/types/theme-mode`、`@/utils/theme/ThemeStorageAdapter`、`@/utils/theme/VersionController` 均无外部导入
- **`themeStorage` 单例**统一了所有持久化操作（主题状态、自定义主题、版本历史）

## 后续

- `types/theme-mode.ts` 目前仅保留 `re-export` 以维持旧导入路径不报错，可在下一次大版本中彻底删除。
- `settings/SettingsPage.tsx` 中高级主题区的 `colorUtils` 仍依赖 `useTheme.tsx` 中的 `getContrastRatio`，该函数已保留在精简后的文件中。
