# ADR-037: 页头表面令牌（不参与反转的实底色）

> **状态**：✅ 已接受　**日期**：2026-10-02　**领域**：前端/UI/UX（主题系统）
> **关联**：M1 T-C1、规范 v1.1.4/v1.1.2、缺陷 D-50/D-54、CHK-23/CHK-24、GATE-04/GATE-05/GATE-11

## 背景

品牌色阶在暗色模式下**整体反转**（`--color-primary-{400..700}` 从深色变浅色，
`bg-primary-500` 暗色 = `#34d399` 浅薄荷）。但 `text-white` 固定前景色**不随主题变化**，
导致页头横幅、主按钮、图标圆等「实底 + 白字」元素在暗色下对比度仅 **1.52:1**
（D-50 实测，远低于 WCAG AA 4.5:1）。D-54 进一步发现 `.surface-primary:hover`
暗色仅 **1.13:1**（比 D-50 本身更差）。

根因：原实现让「实底」直接消费会反转的色阶令牌（`--color-primary-500`），
而色阶反转是为**浅色背景上的品牌色**设计的（色阶反转后在深色画布上仍可读），
但**实底 + 固定白字**需要的是**始终深底**的令牌。

## 决策

引入一组**不参与色阶反转**的表面令牌，专用于承载白色前景的实底：

| 令牌 | 亮色 | 暗色 | 说明 |
|:-----|:-----|:-----|:-----|
| `--color-primary-surface` | `#047857` | `#065f46` | 实底填充（页头/主按钮/图标圆） |
| `--color-on-primary-surface` | `#ffffff` | `#ffffff` | 实底前景（两模式同值） |
| `--color-primary-surface-hover` | `#065f46` | `#047857` | hover 态（比 base 更深/略亮） |

约束（CHK-23/24、C-24）：
- **禁止**将品牌色阶背景类（`bg-primary-{400..700}`）与 `text-white` 搭配。
- 实底 + 白字**必须**用 `--color-primary-surface` / `--color-on-primary-surface` 成对。
- GATE-04 扫描「反转色阶 + text-white」元素，GATE-05 验证实底对比度，
  GATE-11 验证表面令牌含 hover 态对比度（≥4.5:1 AA）。

实测对比度：亮 `#047857` 白字 **5.55:1**（AA）/ 暗 `#065f46` 白字 **7.78:1**（AAA）；
hover 亮 `#065f46` **7.53:1** / 暗 `#047857` **5.08:1**，全部达标。

## 后果

- **正面**：暗色页头/主按钮/图标圆白字对比度 1.52:1 → ≥4.85:1（D-50 修复验收）；
  hover 态 1.13:1 → ≥5.08:1（D-54 修复验收）；GATE-04/05/11 三重门禁锁死回归。
- **负面 / 约束**：表面令牌是「双模式各自定义」的（非 var() 组合），
  若将来改品牌色需同步更新 4 个值（2 模式 × 2 态）；已在 T-G2 中登记为
  DIVERGENT 项（`--color-primary-surface/-hover` 保持字面量，不组合）。

## 备选方案（已否决）

- **让色阶令牌不反转**：破坏暗色画布上浅色背景的品牌色可读性（色阶反转的原始目的），否决。
- **实底用 `currentColor` 动态计算**：无法保证白字对比度恒达标，否决。
