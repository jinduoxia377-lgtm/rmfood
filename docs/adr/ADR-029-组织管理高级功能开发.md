## 背景

在完成了 UI/UX 一致性和基础功能补全后，需要为组织管理页面添加高级功能以提升用户体验和生产效率。

## 决策

### 4.1 组织克隆功能

**方案**：新增 `cloneOrganization` API 方法和克隆对话框

**实现**：
- `useOrganizations.ts` 新增 `cloneOrganization(id, newName?)` 方法
- 创建 `CloneOrgDialog.tsx` 组件，支持：
  - 显示源组织信息（名称、Slug、计划）
  - 自定义副本名称（默认追加"副本"后缀）
  - 克隆成功后自动跳转
- 在 `OrganizationList` 卡片视图中添加克隆按钮（复制图标）

**API 接口**：
```
POST /api/v1/organizations/:id/clone
{ "name": "新名称" }
→ { Organization }
```

### 4.2 键盘快捷键系统

**方案**：创建 `useOrgKeyboardShortcuts` Hook

**快捷键映射**：
| 快捷键 | 功能 |
|--------|------|
| `n` | 新建组织 |
| `/` | 聚焦搜索框 |
| `g o` | 切换到概览 |
| `g m` | 切换到我的组织 |
| `g a` | 切换到全部 |
| `g t` | 切换到数据分析 |
| `Escape` | 关闭弹窗/筛选面板 |

**设计要点**：
- 两键序列使用 800ms 超时窗口
- 输入框中禁用快捷键（避免冲突）
- 右上角显示快捷键提示（大屏时）

### 4.3 最近访问记录

**方案**：创建 `useRecentOrganizations` Hook，使用 localStorage 持久化

**功能**：
- 记录最近 10 个访问过的组织
- 自动去重，最新访问排最前
- 存储结构：`{ id, name, slug, visitedAt }[]`
- 在概览页展示最近访问的快速入口

### 4.4 集成配置完善

**变更**：
- API 密钥管理从 `coming-soon` 升级为 `available`
- 修正集成卡片图标（Clock → ArrowRight）

## 影响评估

| 维度 | 影响 |
|------|------|
| 用户体验 | 大幅提升操作效率，快捷键和克隆减少重复工作 |
| 性能 | 无显著影响（localStorage 操作轻量） |
| 兼容性 | 向后兼容，新功能默认关闭（按需激活） |
| 后端依赖 | 克隆功能依赖后端 `/organizations/:id/clone` 接口 |

## 后续优化方向

1. **WebSocket 实时通知**：接入实时消息推送，显示组织活动通知
2. **虚拟滚动**：当组织数量超过 500 时引入虚拟化列表
3. **批量导入**：支持 CSV 批量导入成员
4. **组织模板**：预置常用组织模板（研发、产品、市场等）
