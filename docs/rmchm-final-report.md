## 六、技术架构说明

### 6.1 合并策略（三级匹配）

```
第一级：TCMSP_id 精确匹配（698条中493条成功）
第二级：name_latin 精确匹配
第三级：name_cn 精确匹配 + 别名交叉匹配
第四级：智能图片匹配规则（括号提取+前缀去除+模糊匹配）
```

### 6.2 图片匹配算法

```python
智能匹配优先级：
1. 已匹配图片直接跳过
2. 规则映射（IMAGE_HERB_RULES字典）
3. 括号内容提取匹配（如"姜（生姜、干姜）"→"生姜"+"干姜"）
4. 去除"鲜/"前缀匹配
5. 模糊匹配（相似度≥0.85）
```

### 6.3 数据质量保障

- OB%异常值截断（>100% → 100%）
- 多源ID交叉验证（TCMSP/SymMap/TCMID/TCM-ID/HERBDB）
- 图片匹配完整性检查（100%目标）
- 字段覆盖率统计（四气97.7%，归经92.1%）
