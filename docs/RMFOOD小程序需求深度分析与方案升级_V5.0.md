## 二、需求深度分析

### 2.1 需求1：配方生成功能

#### 功能定位
这是RMFOOD主项目的**核心能力**，在小程序中需要完整保留。

#### 核心流程
```
用户输入症状/目标 → AI体质分析 → 配方生成 → 详情展示 → 收藏/分享
     ↑                                  ↓
   历史记录 ←—————————————— 效果跟踪反馈
```

#### 关键功能点
| 功能 | 说明 | 技术要点 |
|------|------|---------|
| 智能问诊 | 引导用户提供症状、体质、目标 | 多轮对话、意图识别 |
| 配方生成 | 基于知识库生成个性化配方 | 算法驱动、多目标优化 |
| 方解说明 | 解释配方科学机理 | AI生成、专业知识库 |
| 禁忌提示 | 明确标注不适用人群 | 规则引擎、安全知识库 |
| 效果跟踪 | 记录用户反馈，优化推荐 | 数据分析、模型迭代 |

#### 与其他功能的关联
```
配方生成 ←→ 配料分析（用户可对比自己配置的配方与市售产品）
配方生成 ←→ 电商同步（推荐配方后，可一键购买食材）
```

### 2.2 需求2：配料表扫描分析

#### 功能定位
这是小程序的**差异化竞争力**，解决用户日常消费痛点。

#### 参考OpenFoodFacts
OpenFoodFacts是全球最大的开放食品数据库，核心价值：
- 覆盖全球200+国家的150万+食品数据
- 开源数据，可合法使用
- 包含营养成分、添加剂、过敏原等详细信息

#### 核心流程
```
拍照/扫描 → 识别文字 → 匹配数据库 → 分析成分 → 健康评估 → 给出建议
                ↑
          OCR识别（腾讯/百度）
```

#### 关键功能点
| 功能 | 说明 | 技术要点 |
|------|------|---------|
| 图像识别 | 拍摄或选择图片进行OCR | 腾讯云OCR、百度OCR |
| 成分匹配 | 将识别成分与数据库匹配 | OpenFoodFacts API、自建营养库 |
| 营养计算 | 按GB 28050计算营养标签 | 后端计算服务 |
| 健康评分 | 综合评估食品健康程度 | 算法模型、规则引擎 |
| 添加剂识别 | 识别并警示不安全添加剂 | 知识库、法规标准 |

#### 评估标准设计
```
健康评分算法（100分制）：

基础分：100分

扣分项：
- 高糖（>10g/100g）：-15分
- 高脂（>15g/100g）：-10分
- 高钠（>600mg/100g）：-10分
- 反式脂肪：-20分
- 人工添加剂：-5分/种
- 过敏原（未标注）：-10分

加分项：
- 高膳食纤维：+10分
- 高蛋白：+10分
- 富含 vitamin/mineral：+5分/种
- 药食同源成分：+15分

最终分级：
- 优秀：85-100分 ⭐⭐⭐⭐⭐
- 良好：70-84分 ⭐⭐⭐⭐
- 一般：50-69分 ⭐⭐⭐
- 较差：30-49分 ⭐⭐
- 差：0-29分 ⭐
```

### 2.3 需求3：电商平台产品同步

#### 功能定位
这是小程序的**创新扩展**，打通线上线下消费场景。

#### 电商平台数据源
| 平台 | 数据来源 | 技术可行性 | 备注 |
|------|---------|-----------|------|
| 淘宝/天猫 | 淘宝开放平台API | ✅ 可行 | 需要申请开发者权限 |
| 京东 | 京准通开放平台 | ✅ 可行 | 需要企业资质 |
| 抖音 | 抖音开放平台 | ✅ 可行 | 电商能力逐步开放 |
| 拼多多 | 暂未开放官方API | ⚠️ 困难 | 需考虑合规方案 |

#### 核心流程
```
用户选择产品 → 获取产品ID → 同步产品信息 → 分析配料表 → 给出评价
     ↑                                              ↓
  搜索/扫码                                收藏/分享/对比
```

#### 关键功能点
| 功能 | 说明 | 技术要点 |
|------|------|---------|
| 产品搜索 | 按名称/分类搜索商品 | 各平台API、搜索引擎 |
| 信息同步 | 实时获取产品详情 | API调用、定时同步 |
| 配料分析 | 自动分析产品配料表 | 结合需求2的功能 |
| 价格对比 | 多平台价格对比 | 数据聚合、比价算法 |
| 一键购买 | 跳转电商平台购买 | DeepLink、Universal Link |

#### 数据同步策略
```
实时同步（关键数据）：
├── 产品价格、库存
├── 用户评价、销量
└── 促销活动

定时同步（基础数据）：
├── 产品基本信息
├── 配料表、营养成分
└── 产品图片

增量同步（更新数据）：
├── 新增产品
├── 产品下架
└── 价格变动
```

### 3.2 场景联动示例

**场景1：用户想改善睡眠**
```
1. 用户在AI对话中输入"我最近睡眠不好"
   ↓
2. AI生成安神助眠配方（需求1）
   ↓
3. 配方包含：酸枣仁15g、茯苓10g、龙眼肉10g
   ↓
4. 系统推荐购买食材（需求3）
   ↓

   ↓

   ↓
4. 发现评分较低，系统推荐替代配方（需求1）
   ↓
5. 系统推荐更健康的同类产品（需求3）
   ↓
6. 用户直接跳转电商平台购买
```

**场景3：用户想对比产品**
```
1. 用户在电商平台看到两款同类产品
   ↓

   ↓
3. 系统分别分析两款产品的营养成分（需求2）
   ↓
4. 生成对比报告，突出差异
   ↓
5. 用户一键购买推荐产品（需求3）
```
