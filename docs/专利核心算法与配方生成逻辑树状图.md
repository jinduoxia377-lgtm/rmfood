# 专利核心算法与配方生成逻辑树状图  
（基于 US 11,742,060 B2 全文）

## 一、系统架构（Apparatus Components）

### 1. 信号编码器（Signal Encoder）  
- **输入**：目标属性（target attributes），如产品类别、粘度、pH值等  
- **处理**：将目标属性编码为信号（支持独热编码、连续值映射或离散化）  
- **输出**：目标属性信号（signal），传递给生成器子系统、配方选择器（可选也传递给预测器/判别器）

### 2. 生成器子系统（Generator Subsystem）  
- 包含一个或多个**神经网络生成器序列子系统**，可选包含**模板子系统**  
#### 2.1 生成器序列子系统（Generator Sequence Subsystem）  
- **核心网络**：循环子网络（recurrent subnetwork）  
  - 堆叠长短期记忆单元（stacked LSTM cells）  
  - 可选外部记忆组件（external memory）  
- **输出层**：时间分布密集层（time-distributed dense layers）  
  - 可生成：  
    - 成分样本的分数分布（softmax层）  
    - 成分功能的分数分布  
    - 成分浓度区间的分数分布  
    - 或直接输出数值（如浓度值，使用线性层）  
- **生成方式**：**自回归生成**（autoregressive）  
  - 每个时间步生成一个“化学数据样本”（包含成分、浓度、功能、混合阶段等信息）  
  - 当前时间步的输出依赖于之前所有时间步的生成结果  
- **输入**：  
  - 当前化学数据序列（已生成的部分）  
  - 可选：目标属性信号（用于条件生成）  
  - 可选：局部特征、全局特征（如产品类型）  
- **停止条件**：  
  - 网络输出特定停止标记  
  - 或达到预设最大时间步数  

#### 2.2 模板子系统（Template Subsystem）  
- **功能**：在生成过程中修改化学数据序列  
- **操作方式**：  
  - 提供基序列（base sequence），生成器从基序列之后开始生成  
  - 在特定时间步后插入新步骤  
  - 条件触发修改（如特定成分出现时）  
- **与生成器序列子系统的关系**：串联工作，可有多组并行  

### 3. 预测器子系统（Predictor Subsystem，可选）  
- **核心网络**：循环子网络（可含外部记忆）  
- **输入**：完整的化学数据序列（代表一个配方）  
- **输出**：配方属性的预测值  
  - 分类属性：softmax输出层（如是否含石化成分）  
  - 数值属性：线性层输出（如pH值、粘度）  
- **用途**：为配方选择器提供属性评分依据  

### 4. 判别器子系统（Discriminator Subsystem，可选）  
- **核心网络**：  
  - 循环子网络（可含外部记忆）  
  - 或卷积子网络（如堆叠1D卷积层）  
- **输入**：完整的化学数据序列  
- **输出**：配方来源分类（二分类）  
  - 来源A：由生成器产生  
  - 来源B：属于市场现有产品集  
- **用途**：确保输出配方不是简单复制现有产品  

### 5. 配方选择器（Formulation Selector）  
- **输入**：  
  - 生成器输出的化学数据序列  
  - 目标属性信号（来自信号编码器）  
  - 预测器输出（若存在）  
  - 判别器输出（若存在）  
- **处理**：  
  - 将化学数据序列转化为实际配方（如浓度归一化补齐至100%）  
  - 根据目标属性、优先级、预测/判别分数进行多目标优化  
- **选择策略**：  
  - 纯随机选择（无预测器/判别器时）  
  - 按优先级逐级优化（先满足最高优先级属性，再优化次高）  
  - 加权组合多个目标属性  
- **输出**：选定的一个或多个配方（作为最终结果）  

### 6. 调优器子系统（Tuner / Reinforcement Learning Subsystem，可选）  
- **用途**：训练阶段优化生成器权重  
- **输入**：  
  - 目标属性信号  
  - 生成器序列子系统  
  - 预测器输出（若存在）  
  - 判别器输出（若存在）  
- **方法**：强化学习（如策略梯度）  
- **目标**：修改生成器权重，使生成配方更符合目标属性（提高预测器分数、降低判别器识别为机器生成的概率）  

## 二、配方生成逻辑（方法流程，对应于权利要求1、8、22）

### 步骤0：准备（训练阶段，可选）  
- 随机初始化神经网络参数  
- 监督预训练：使用现有配方数据，通过随机梯度下降+反向传播训练生成器序列子系统  
- 强化学习调优：通过调优器改进生成器  

### 步骤1：接收输入  
- 接收一组目标属性（如：产品类别、粘度、pH值）  
- 接收一组优先级值（priority values）对应各目标属性  

### 步骤2：编码目标属性  
- 信号编码器将目标属性编码为信号（可选的独热编码、离散化等）  

### 步骤3：生成样本配方（第一神经网络）  
- 生成器子系统基于目标属性信号（或直接基于目标属性）生成一组样本配方  
- 每个样本配方包括：  
  - 成分列表（按浓度降序排列）  
  - 每个成分的特征值（浓度百分比、功能、混合阶段等）  
- 生成过程为自回归，每个时间步生成一个成分及其特征  

### 步骤4：评分（可选，取决于是否有预测器/判别器）  
- 若存在预测器：对每个样本配方预测其属性值（如pH、粘度）  
- 若存在判别器：判断每个样本配方的来源（生成 vs 市场）  
- 根据预测/判别结果计算每个样本配方的分数（分数反映与目标属性的匹配程度）  

### 步骤5：选择最佳配方  
- 配方选择器基于分数、目标属性及优先级，选择一个分数最高的样本配方  
- 若有多个目标属性，按优先级或加权组合进行优化  

### 步骤6：确定来源  
- 判别器（或其它方法）确定所选配方的来源  
- 判断该来源是否属于预定组（如“由生成器产生”或“非现有市场产品”）  

### 步骤7：生成报告  
- 若来源属于预定组，则生成包含该配方的报告作为最终化学产品配方  
- 输出配方可包含所有成分及浓度信息  

### 步骤8：迭代（可选）  
- 可重复步骤3-7直到满足预定条件（如达到目标属性阈值、时间限制、或生成特定标记）  
- 每次迭代可基于前一次选择结果进行修改（如修改权重、使用前一次配方作为模板）  

## 三、关键算法细节

### 3.1 自回归生成（Autoregressive Generation）  
- 每个时间步t，循环子网络接收当前序列（前t-1步的输出），生成替代表示（alternative representation）  
- 输出层根据替代表示生成该时间步的成分分布、浓度分布等  
- 通过采样或argmax选择具体成分，然后进入下一步  

### 3.2 多目标优化（Multi-Objective Optimization）  
- 支持按优先级排序（lexicographic optimization）  
- 支持加权组合（weighted sum）  
- 可同时优化分类属性和数值属性  

### 3.3 强化学习调优（Reinforcement Learning Tuning）  
- 利用策略梯度（policy gradient）方法  
- 奖励函数基于预测器对目标属性的预测值（如pH接近目标程度）和判别器输出（希望判别器认为生成的配方是“真实”的）  
- 通过调优器更新生成器权重，提升后续生成配方的质量  

### 3.4 模板系统（Template System）  
- 可提供先验知识（如已知稳定配方的前几步）  
- 支持在生成过程中插入或修改步骤，实现条件控制  

## 四、应用场景示例  
- **个人护理产品**：如面部保湿霜  
- **目标属性**：产品类别（护肤）、粘度（5000 cP）、pH值（5.5）、各成分浓度范围、混合阶段顺序等
