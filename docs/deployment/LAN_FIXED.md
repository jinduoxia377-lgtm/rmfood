## 📋 故障排查

### 问题：还是无法访问

**检查步骤**：

1. **验证服务运行**
   ```bash
   netstat -ano | findstr ":3001"
   netstat -ano | findstr ":8000"
   ```
   应该看到 `0.0.0.0:3001 LISTENING` 和 `0.0.0.0:8000 LISTENING`

2. **验证网络连接**
   ```bash
   ping 192.168.137.1
   ```
   应该收到回复

3. **检查防火墙**
   - Windows：设置 > 隐私和安全 > Windows Defender 防火墙
   - 允许 Python 和 Node.js 通过防火墙

4. **测试 API**
   ```
   http://192.168.137.1:8000/api/v1
   ```
   在浏览器中直接访问

### 问题：连接被拒绝

**原因**：防火墙或服务未启动

**解决**：
1. 检查防火墙规则
2. 重启服务：`start-lan.bat`
3. 等待 30 秒后再试

### 问题：无法到达主机

**原因**：不在同一网络

**解决**：
1. 确认两台设备在同一 WiFi
2. 使用 `ipconfig` 检查 IP 地址
3. 确保 IP 前三段相同（如 192.168.137.x）
