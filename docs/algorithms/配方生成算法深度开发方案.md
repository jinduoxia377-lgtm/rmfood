### 1.3 关键差距矩阵

| 维度 | 现有系统 | 专利要求 | 差距等级 |
|------|---------|---------|---------|
| **生成范式** | 批量采样+评估（贝叶斯/遗传） | **自回归序列生成**（LSTM逐个成分） | 🔴 核心缺失 |
| **先验知识注入** | 经典方剂种子（种群初始化） | **模板子系统**（生成过程中动态干预） | 🟠 深度不足 |
| **属性预测** | FormulaEvaluator后验评分 | **预测器**（生成前预测→引导生成） | 🔴 核心缺失 |
| **判别机制** | 无 | **判别器**（防止生成重复市场配方） | 🔴 核心缺失 |
| **优化范式** | 多目标优化（Pareto/加权） | **RL策略梯度**（端到端生成器调优） | 🟠 可补充 |
| **肽类生成** | 静态模板 | 无（专利未涉及肽类） | ✅ 无差距 |
| **结构构建** | 按用量降序→君臣佐使 | 无（专利侧重生成而非结构） | ✅ 已有优势 |
| **数据规模** | 20味药材硬编码 | 可扩展成分库 | 🟡 需升级 |

## 三、分模块深度设计方案

### 3.1 信号编码器（Signal Encoder）

**位置**：`app/services/ai/models/signal_encoder.py`

```python
"""
信号编码器 — 将配方需求编码为神经网络可理解的信号

支持三种编码模式：
1. 独热编码（目标功效维度）
2. 连续值映射（浓度、pH、粘度等数值约束）
3. 结构化标记（产品类别、目标人群）
"""

import torch
import torch.nn as nn
import numpy as np
from typing import Dict, List, Optional, Tuple


class SignalEncoder(nn.Module):
    """配方需求信号编码器"""

    def __init__(
        self,
        n_effects: int = 20,       # 功效类别数
        n_categories: int = 10,    # 产品类别数
        n_target_groups: int = 5,  # 目标人群数
        continuous_dim: int = 4,   # 连续约束维度
    ):
        super().__init__()
        self.n_effects = n_effects
        self.n_categories = n_categories
        self.n_target_groups = n_target_groups
        self.continuous_dim = continuous_dim

        # 可学习嵌入
        self.effect_embed = nn.Embedding(n_effects, 16)
        self.category_embed = nn.Embedding(n_categories, 8)
        self.group_embed = nn.Embedding(n_target_groups, 8)

        # 编码输出维度 = 16 + 8 + 8 + 4 = 36
        self.output_dim = 16 + 8 + 8 + continuous_dim

    def encode(
        self,
        target_effects: List[str],
        product_category: Optional[str] = None,
        target_group: str = "adult",
        continuous_constraints: Optional[Dict[str, float]] = None,
        effect_index_map: Dict[str, int] = None,
        category_index_map: Dict[str, int] = None,
        group_index_map: Dict[str, int] = None,
    ) -> torch.Tensor:
        """
        编码配方需求为信号向量

        Returns:
            tensor of shape (1, output_dim)
        """
        # 功效独热编码
        effect_vec = torch.zeros(1, self.n_effects)
        if effect_index_map:
            for eff in target_effects:
                if eff in effect_index_map:
                    idx = effect_index_map[eff]
                    effect_vec[0, idx] = 1.0
            # 嵌入层
            effect_embed = self.effect_embed(
                torch.tensor([effect_index_map[eff] for eff in target_effects
                             if eff in effect_index_map])
            ).mean(dim=0).unsqueeze(0)  # (1, 16)
        else:
            effect_embed = torch.zeros(1, 16)

        # 产品类别编码
        cat_idx = category_index_map.get(product_category, 0) if category_index_map and product_category else 0
        cat_embed = self.category_embed(torch.tensor([[cat_idx]]))  # (1, 8)

        # 目标人群编码
        group_idx = group_index_map.get(target_group, 0) if group_index_map else 0
        group_embed = self.group_embed(torch.tensor([[group_idx]]))  # (1, 8)

        # 连续约束
        cont_vec = torch.tensor(
            [continuous_constraints.get(k, 0.5) for k in sorted(continuous_constraints.keys())[:self.continuous_dim]]
            if continuous_constraints else [0.5] * self.continuous_dim
        ).unsqueeze(0)  # (1, 4)

        return torch.cat([effect_embed, cat_embed, group_embed, cont_vec], dim=-1)
```

**关键设计决策**：
- 使用可学习嵌入而非硬编码独热，允许模型学习功效之间的语义关系
- 连续约束维度可扩展（pH、粘度、成本上限等）
- 与现有 `_EFFICACY_TO_HERBS` 索引兼容

### 3.2 自回归LSTM生成器（核心创新）

**位置**：`app/services/ai/models/autoregressive_generator.py`

```python
"""
自回归配方生成器 — 基于专利 US 11,742,060 B2

核心架构：
- 输入：信号编码器输出 (36维)
- 核心：3层堆叠LSTM + 外部记忆组件
- 输出：每时间步生成 {成分ID, 浓度区间, 功能标签, 混合阶段}
- 停止条件：生成STOP标记或达到max_sequence_length
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Dict, List, Optional, Tuple
import logging

logger = logging.getLogger(__name__)


class AutoregressiveFormulaGenerator(nn.Module):
    """
    自回归配方生成器

    架构:
    ┌──────────────┐    ┌─────────────────┐    ┌──────────────┐
    │ Signal Input │───→│ Stacked LSTM    │───→│ Time-Dist.   │
    │ (36 dim)     │    │ (3 layers, 128) │    │ Dense Layers │
    └──────────────┘    └─────────────────┘    └──────┬───────┘
                                                      │
                    ┌─────────────────────────────────┼──────────────────┐
                    ↓                                 ↓                  ↓
              ┌──────────┐                    ┌───────────┐      ┌──────────┐
              │Herb Dist │                    │Dosage Dist│     │Stop Prob │
              │ softmax  │                    │  linear   │      │ sigmoid  │
              └──────────┘                    └───────────┘      └──────────┘
    """

    def __init__(
        self,
        input_dim: int = 36,
        hidden_dim: int = 128,
        n_layers: int = 3,
        n_herbs: int = 200,       # 候选药材数（可扩展）
        n_dosage_bins: int = 10,  # 浓度区间离散化
        n_functions: int = 15,    # 功能标签类别
        dropout: float = 0.2,
    ):
        super().__init__()
        self.hidden_dim = hidden_dim
        self.n_herbs = n_herbs
        self.n_dosage_bins = n_dosage_bins
        self.n_functions = n_functions

        # 输入投影
        self.input_proj = nn.Linear(input_dim, hidden_dim)

        # 堆叠LSTM
        self.lstm = nn.LSTM(
            input_size=hidden_dim,
            hidden_size=hidden_dim,
            num_layers=n_layers,
            batch_first=True,
            dropout=dropout if n_layers > 1 else 0.0,
        )

        # 外部记忆组件（可选，提升序列长度依赖捕获）
        self.memory = nn.Parameter(torch.randn(1, n_layers, hidden_dim))

        # 输出层：成分分布（softmax）
        self.herb_head = nn.Linear(hidden_dim, n_herbs)

        # 输出层：浓度区间分布
        self.dosage_head = nn.Linear(hidden_dim, n_dosage_bins)

        # 输出层：功能标签分布
        self.function_head = nn.Linear(hidden_dim, n_functions)

        # 停止标记概率
        self.stop_head = nn.Linear(hidden_dim, 1)

        # 混合阶段（离散：pre_mix, main_mix, post_mix）
        self.stage_head = nn.Linear(hidden_dim, 3)

    def forward(
        self,
        signal: torch.Tensor,           # (batch, input_dim)
        herb_vocab: List[str] = None,   # 可选：动态药材词汇表
        max_seq_len: int = 12,
        temperature: float = 1.0,
        top_k: int = 0,
    ) -> List[Dict]:
        """
        自回归生成配方序列

        Args:
            signal: 信号编码器输出
            herb_vocab: 当前候选药材词汇表（用于约束生成）
            max_seq_len: 最大生成序列长度
            temperature: 采样温度（<1更确定性，>1更多样）
            top_k: Top-k采样（0=不过滤）

        Returns:
            list of generated formula steps
        """
        batch_size = signal.shape[0]
        device = signal.device

        # 初始输入：信号嵌入
        x = self.input_proj(signal).unsqueeze(1)  # (batch, 1, hidden)

        # 隐藏状态初始化
        h0 = torch.zeros(self.lstm.num_layers, batch_size, self.hidden_dim).to(device)
        c0 = torch.zeros(self.lstm.num_layers, batch_size, self.hidden_dim).to(device)

        # 注入外部记忆
        mem = self.memory.expand(batch_size, -1, -1).to(device)
        h0 = h0 + mem

        generated_steps = []
        sequence_done = torch.zeros(batch_size, dtype=torch.bool, device=device)

        for t in range(max_seq_len):
            # LSTM前向
            output, (hn, cn) = self.lstm(x, (h0, c0))  # output: (batch, 1, hidden)

            hidden = output[:, -1, :]  # (batch, hidden)

            # 并行预测各分布
            herb_logits = self.herb_head(hidden) / temperature
            dosage_logits = self.dosage_head(hidden) / temperature
            function_logits = self.function_head(hidden) / temperature
            stop_logits = self.stop_head(hidden).squeeze(-1)  # (batch,)
            stage_logits = self.stage_head(hidden) / temperature

            # Top-k过滤（可选）
            if top_k > 0:
                top_k_values, top_k_indices = torch.topk(herb_logits, top_k, dim=-1)
                herb_logits = torch.where(
                    herb_logits >= top_k_values[:, -1:],
                    herb_logits,
                    torch.tensor(-float('inf'), device=device)
                )

            # 采样
            herb_probs = F.softmax(herb_logits, dim=-1)
            herb_idx = torch.multinomial(herb_probs, 1).squeeze(-1)  # (batch,)

            # 停止判断
            stop_prob = torch.sigmoid(stop_logits)
            should_stop = stop_prob > 0.7  # 阈值可调

            # 更新序列
            if t == 0:
                selected_herbs = herb_idx.unsqueeze(1)
                selected_dosages = torch.multinomial(F.softmax(dosage_logits, dim=-1), 1).squeeze(-1)
                selected_functions = torch.multinomial(F.softmax(function_logits, dim=-1), 1).squeeze(-1)
                selected_stages = torch.multinomial(F.softmax(stage_logits, dim=-1), 1).squeeze(-1)
            else:
                selected_herbs = torch.cat([selected_herbs, herb_idx.unsqueeze(1)], dim=1)
                selected_dosages = torch.cat([selected_dosages,
                                              torch.multinomial(F.softmax(dosage_logits, dim=-1), 1).squeeze(-1).unsqueeze(1)], dim=1)
                selected_functions = torch.cat([selected_functions,
                                                torch.multinomial(F.softmax(function_logits, dim=-1), 1).squeeze(-1).unsqueeze(1)], dim=1)
                selected_stages = torch.cat([selected_stages,
                                             torch.multinomial(F.softmax(stage_logits, dim=-1), 1).squeeze(-1).unsqueeze(1)], dim=1)

            # 更新隐藏状态
            h0, c0 = hn, cn

            # 检查停止条件
            new_stops = should_stop | sequence_done
            if torch.all(new_stops):
                break
            sequence_done = new_stops

            # 将选中的成分嵌入后传入下一步
            herb_embed = self._get_herb_embed(herb_idx, device)  # (batch, hidden)
            x = herb_embed.unsqueeze(1)

        # 组装结果
        results = []
        for b in range(batch_size):
            seq_len = selected_herbs.shape[1]
            step = {}
            for t in range(seq_len):
                hid = selected_herbs[b, t].item()
                if herb_vocab and hid < len(herb_vocab):
                    herb_name = herb_vocab[hid]
                else:
                    herb_name = f"herb_{hid}"
                step[herb_name] = {
                    "dosage_bin": selected_dosages[b, t].item(),
                    "function": selected_functions[b, t].item(),
                    "stage": selected_stages[b, t].item(),
                }
            results.append(step)

        return results

    def _get_herb_embed(self, herb_idx: torch.Tensor, device: torch.device) -> torch.Tensor:
        """获取成分嵌入（简化版，实际可接预训练嵌入）"""
        # TODO: 加载预训练 herb embedding
        return torch.randn(herb_idx.shape[0], self.hidden_dim, device=device)

    def generate_with_constraints(
        self,
        signal: torch.Tensor,
        herb_vocab: List[str],
        min_herbs: int = 3,
        max_herbs: int = 12,
        exclude_herbs: List[str] = None,
    ) -> Dict[str, float]:
        """
        带约束的配方生成

        Returns:
            {herb_id: dosage_float}  用量向量
        """
        exclude_set = set(exclude_herbs or [])
        valid_vocab = [h for h in herb_vocab if h not in exclude_set]

        # 生成序列
        steps = self.forward(signal, herb_vocab=valid_vocab, max_seq_len=max_herbs)

        if not steps:
            return {}

        formula = {}
        for step in steps:
            for herb_id, attrs in step.items():
                if herb_id not in formula:
                    # 将 dosage_bin (0~9) 映射到实际用量
                    dosage_bin = attrs["dosage_bin"]
                    # TODO: 根据药材属性动态映射
                    formula[herb_id] = 5.0 + dosage_bin * 2.0  # 简化映射

        # 约束：最少成分数
        if len(formula) < min_herbs:
            # 补充随机有效药材
            pass

        return formula
```

**关键技术要点**：
- 自回归特性：每步输出依赖前序所有步骤，天然支持"君臣佐使"结构涌现
- 停止标记机制：网络自主决定何时停止添加药材
- Top-k / 温度采样：平衡生成质量与多样性
- 动态词汇表：支持不同场景下的候选药材池

### 3.3 预测器子系统（Predictor Subsystem）

**位置**：`app/services/ai/models/formula_predictor.py`

```python
"""
配方属性预测器 — 预测配方序列的目标属性值

网络架构：
- 输入：完整配方序列（成分ID序列 + 浓度向量）
- 核心：BiLSTM + 注意力机制
- 输出：功效评分、安全评分、口感评分、成本等

与专利的区别：
- 专利：预测pH、粘度等物理属性
- 本项目：预测功效/安全/口感等中医属性
"""

import torch
import torch.nn as nn
from typing import Dict, List, Optional


class FormulaPredictor(nn.Module):
    """配方属性预测器"""

    def __init__(
        self,
        n_herbs: int = 200,
        hidden_dim: int = 128,
        n_output_attrs: int = 7,  # 功效/安全/口感/成本/协同/稳定/ADMET
    ):
        super().__init__()
        self.herb_embed = nn.Embedding(n_herbs, 32)
        self.dosage_embed = nn.Linear(1, 16)  # 浓度编码

        self.bi_lstm = nn.LSTM(
            input_size=32 + 16,
            hidden_size=hidden_dim // 2,
            num_layers=2,
            batch_first=True,
            bidirectional=True,
        )

        self.attention = nn.Linear(hidden_dim, 1)
        self.output_head = nn.Linear(hidden_dim, n_output_attrs)

    def forward(
        self,
        herb_indices: torch.Tensor,   # (batch, seq_len)
        dosages: torch.Tensor,        # (batch, seq_len, 1)
    ) -> torch.Tensor:
        """
        预测配方属性

        Returns:
            (batch, n_output_attrs) 属性向量
        """
        # 嵌入
        herb_emb = self.herb_embed(herb_indices)              # (batch, seq, 32)
        dosage_emb = self.dosage_embed(dosage)                # (batch, seq, 16)
        x = torch.cat([herb_emb, dosage_emb], dim=-1)         # (batch, seq, 48)

        # BiLSTM
        lstm_out, _ = self.bi_lstm(x)                          # (batch, seq, hidden)

        # 注意力加权
        attn_weights = torch.softmax(self.attention(lstm_out), dim=1)
        context = (lstm_out * attn_weights).sum(dim=1)        # (batch, hidden)

        # 属性预测
        return torch.sigmoid(self.output_head(context))       # (batch, 7)
```

**与生成器的联动**：
- 训练阶段：预测器输出作为生成器的奖励信号
- 推理阶段：生成候选配方后，预测器实时评分，筛选Top-K

### 3.4 判别器子系统（Discriminator Subsystem）

**位置**：`app/services/ai/models/formula_discriminator.py`

```python
"""
配方来源判别器 — 判断配方是AI生成还是来自市场现有产品

核心目标：
- 确保生成配方不是对现有产品的简单复制
- 为RL奖励函数提供"新颖性"信号
"""

import torch
import torch.nn as nn


class FormulaDiscriminator(nn.Module):
    """配方来源判别器"""

    def __init__(self, n_herbs: int = 200, hidden_dim: int = 128):
        super().__init__()
        self.herb_embed = nn.Embedding(n_herbs, 32)
        self.lstm = nn.LSTM(32, hidden_dim // 2, num_layers=2, batch_first=True, bidirectional=True)
        self.classifier = nn.Sequential(
            nn.Linear(hidden_dim, 64),
            nn.ReLU(),
            nn.Linear(64, 1),
        )

    def forward(self, herb_indices: torch.Tensor) -> torch.Tensor:
        """
        预测配方来源概率

        Returns:
            (batch, 1) 标量，sigmoid后表示"真实市场产品"的概率
        """
        emb = self.herb_embed(herb_indices)
        lstm_out, _ = self.lstm(emb)
        # 使用最后时间步输出
        context = lstm_out[:, -1, :]
        return self.classifier(context)  # (batch, 1)
```

**使用策略**：
- 训练时：生成器输出 + 判别器评分 = RL奖励
- 推理时：可作为过滤条件，排除判别器认为"与现有产品太相似"的配方

### 3.6 RL调优器（Tuner Subsystem）

**位置**：`app/services/ai/models/rl_tuner.py`

```python
"""
强化学习调优器 — 策略梯度优化生成器权重

奖励函数设计：
R = α·PredictorScore + β·(1 - DiscriminatorProb) + γ·TemplateBonus - δ·SafetyPenalty

其中：
- PredictorScore: 预测器对目标属性的预测值
- DiscriminatorProb: 判别器识别为"真实"的概率（我们希望判别器认为"假"）
- TemplateBonus: 符合经典方剂结构 bonus
- SafetyPenalty: 安全违规惩罚
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Dict, List, Optional
import logging

logger = logging.getLogger(__name__)


class RLFormulaTuner(nn.Module):
    """
    配方生成器RL调优器

    使用 REINFORCE + 基线（Baseline）策略梯度方法：
    - 动作：生成器生成的配方序列
    - 奖励：预测器分数 + 判别器惩罚 + 安全惩罚
    - 策略梯度更新生成器参数
    """

    def __init__(
        self,
        generator: nn.Module,
        predictor: nn.Module,
        discriminator: nn.Module,
        lr: float = 1e-4,
        reward_weights: Dict[str, float] = None,
    ):
        super().__init__()
        self.generator = generator
        self.predictor = predictor
        self.discriminator = discriminator

        # 奖励权重
        self.reward_weights = reward_weights or {
            "predictor_efficacy": 0.30,
            "predictor_safety": 0.25,
            "predictor_taste": 0.10,
            "discriminator_novelty": 0.20,  # 希望判别器认为"假"
            "template_bonus": 0.10,
        }

        # 基线（exponential moving average of rewards）
        self.baseline = 0.5
        self.baseline_decay = 0.99

        # 优化器
        self.optimizer = torch.optim.Adam(
            filter(lambda p: p.requires_grad, generator.parameters()),
            lr=lr,
        )

    def compute_reward(
        self,
        herb_indices: torch.Tensor,
        dosages: torch.Tensor,
        signal: torch.Tensor,
        template_match: float = 0.0,
        safety_penalty: float = 0.0,
    ) -> Dict[str, float]:
        """
        计算复合奖励

        Returns:
            {reward_name: value}
        """
        with torch.no_grad():
            # 预测器评分
            pred_scores = self.predictor(herb_indices, dosages)  # (batch, 7)
            efficacy_score = pred_scores[:, 0].mean().item()
            safety_score = pred_scores[:, 1].mean().item()
            taste_score = pred_scores[:, 2].mean().item()

            # 判别器评分（越低越好，表示"生成"而非"真实"）
            disc_score = self.discriminator(herb_indices).mean().item()
            novelty_reward = 1.0 - disc_score  # 反转：希望判别器认为"假"

        rewards = {
            "predictor_efficacy": efficacy_score,
            "predictor_safety": safety_score,
            "predictor_taste": taste_score,
            "discriminator_novelty": novelty_reward,
            "template_bonus": template_match,
            "safety_penalty": safety_penalty,
        }

        # 加权综合奖励
        total_reward = (
            self.reward_weights["predictor_efficacy"] * efficacy_score
            + self.reward_weights["predictor_safety"] * safety_score
            + self.reward_weights["predictor_taste"] * taste_score
            + self.reward_weights["discriminator_novelty"] * novelty_reward
            + self.reward_weights["template_bonus"] * template_match
            - safety_penalty
        )

        return {**rewards, "total": total_reward}

    def train_step(
        self,
        signal: torch.Tensor,
        herb_vocab: List[str],
        template_name: Optional[str] = None,
        n_samples: int = 32,
    ) -> Dict[str, float]:
        """
        单步RL训练

        Returns:
            训练统计信息
        """
        self.generator.train()
        self.predictor.eval()
        self.discriminator.eval()

        # 生成配方
        with torch.no_grad():
            generated = self.generator.forward(
                signal.repeat(n_samples, 1),
                herb_vocab=herb_vocab,
                max_seq_len=12,
            )

        # 计算奖励（简化：仅使用预测器）
        rewards = []
        for formula in generated:
            # TODO: 将生成的配方转换为 herb_indices + dosages
            # 这里简化处理
            reward = sum(v for k, v in self.compute_reward(
                herb_indices=torch.zeros(1, 1),
                dosages=torch.zeros(1, 1, 1),
                signal=signal,
            ).items() if k != "total") / 5.0
            rewards.append(reward)

        rewards_tensor = torch.tensor(rewards, device=signal.device)

        # 基线更新
        self.baseline = self.baseline * self.baseline_decay + (1 - self.baseline_decay) * rewards_tensor.mean().item()
        advantages = rewards_tensor - self.baseline

        # REINFORCE梯度
        log_probs = self._compute_log_probs(generated, signal.repeat(n_samples, 1))
        loss = -(log_probs * advantages.detach()).mean()

        self.optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(self.generator.parameters(), max_norm=1.0)
        self.optimizer.step()

        return {
            "loss": loss.item(),
            "avg_reward": rewards_tensor.mean().item(),
            "baseline": self.baseline,
        }

    def _compute_log_probs(
        self,
        generated: List[Dict],
        signal: torch.Tensor,
    ) -> torch.Tensor:
        """计算生成序列的对数概率（简化实现）"""
        # TODO: 完整实现
        return torch.zeros(len(generated), device=signal.device)
```

### 3.7 配方选择器（Formula Selector）升级

**位置**：`app/services/ai/models/formula_selector.py`

```python
"""
配方选择器 — 专利核心组件

支持三种选择策略：
1. Lexicographic（优先级逐级优化）
2. Weighted Sum（加权组合）
3. ε-Constraint（约束优化）
"""

import torch
from typing import Dict, List, Optional, Tuple
from dataclasses import dataclass
import logging

logger = logging.getLogger(__name__)


@dataclass
class SelectionPriority:
    """单个优先级的选择规则"""
    objective: str           # 优化目标名称
    direction: str           # "maximize" | "minimize"
    weight: float            # 权重（加权模式下使用）
    threshold: Optional[float] = None  # ε-约束阈值
    tolerance: float = 0.05  # 容差


class FormulaSelector:
    """
    配方选择器

    核心创新：优先级逐级优化（Lexicographic Optimization）
    与传统多目标优化的区别：
    - 传统：加权求和，权重敏感
    - 专利：按优先级严格排序，高优先级目标优先满足
    """

    def __init__(
        self,
        priorities: List[SelectionPriority] = None,
        strategy: str = "lexicographic",
    ):
        self.priorities = priorities or self._default_priorities()
        self.strategy = strategy  # "lexicographic" | "weighted" | "epsilon"

    @staticmethod
    def _default_priorities() -> List[SelectionPriority]:
        """默认优先级配置（中医配方场景）"""
        return [
            SelectionPriority("efficacy", "maximize", weight=0.30),
            SelectionPriority("safety", "maximize", weight=0.25),
            SelectionPriority("taste", "maximize", weight=0.10),
            SelectionPriority("cost_efficiency", "maximize", weight=0.15),
            SelectionPriority("synergy", "maximize", weight=0.10),
            SelectionPriority("stability", "maximize", weight=0.10),
        ]

    def select(
        self,
        candidates: List[Dict],
        target_effects: List[str],
        constraints: Optional[Dict] = None,
    ) -> List[Dict]:
        """
        选择最优配方

        Args:
            candidates: 候选配方列表
            target_effects: 目标功效
            constraints: 约束条件

        Returns:
            选中的配方（Top-K）
        """
        if self.strategy == "lexicographic":
            return self._select_lexicographic(candidates)
        elif self.strategy == "weighted":
            return self._select_weighted(candidates)
        elif self.strategy == "epsilon":
            return self._select_epsilon(candidates, constraints or {})
        else:
            raise ValueError(f"Unknown strategy: {self.strategy}")

    def _select_lexicographic(self, candidates: List[Dict]) -> List[Dict]:
        """
        优先级逐级优化

        1. 按第一优先级排序，选出帕累托最优子集
        2. 在第一优先级相同的前提下，按第二优先级排序
        3. 依此类推
        """
        if not candidates:
            return []

        sorted_candidates = list(candidates)

        for priority in self.priorities:
            if len(sorted_candidates) <= 1:
                break

            # 按当前优先级排序
            key = priority.objective
            reverse = priority.direction == "maximize"
            sorted_candidates.sort(
                key=lambda c: c.get(key, 0),
                reverse=reverse,
            )

            # 找出第一优先级相同的最优子集（容差内）
            best_value = sorted_candidates[0].get(key, 0)
            tol = priority.threshold or (best_value * priority.tolerance if best_value > 0 else 0.05)
            sorted_candidates = [
                c for c in sorted_candidates
                if abs(c.get(key, 0) - best_value) <= tol
            ]

        return sorted_candidates[:3]  # Top-3

    def _select_weighted(self, candidates: List[Dict]) -> List[Dict]:
        """加权组合选择"""
        for c in candidates:
            c["_weighted_score"] = sum(
                p.weight * c.get(p.objective, 0)
                for p in self.priorities
            )
        sorted_candidates = sorted(
            candidates,
            key=lambda c: c.get("_weighted_score", 0),
            reverse=True,
        )
        return sorted_candidates[:3]

    def _select_epsilon(self, candidates: List[Dict], constraints: Dict) -> List[Dict]:
        """ε-约束法"""
        feasible = []
        for c in candidates:
            valid = True
            for key, threshold in constraints.items():
                if key in c:
                    if threshold.get("min") and c[key] < threshold["min"]:
                        valid = False
                        break
                    if threshold.get("max") and c[key] > threshold["max"]:
                        valid = False
                        break
            if valid:
                feasible.append(c)

        if not feasible:
            return candidates[:3]  # 无可行解，返回Top-3

        return self._select_lexicographic(feasible)
```

```python
from .signal_encoder import SignalEncoder
from .autoregressive_generator import AutoregressiveGenerator
from .formula_predictor import FormulaPredictor
from .formula_discriminator import FormulaDiscriminator
from .template_subsystem import TemplateSubsystem
from .formula_selector import FormulaSelector, SelectionPriority

logger = logging.getLogger(__name__)


class UnifiedFormulaEngine:
    """
    统一配方生成引擎

    生成流程：
    1. 编码用户需求为信号
    2. 选择/构建模板（经典方剂注入）
    3. 自回归生成配方序列
    4. 预测器实时评分
    5. 判别器新颖性检查
    6. 选择器优选Top-K
    7. 安全合规检查
    8. 君臣佐使结构构建
    """

    def __init__(
        self,
        herb_vocab: List[str] = None,
        device: str = "cpu",
        use_gpu: bool = False,
    ):
        self.device = device if not use_gpu or not torch.cuda.is_available() else "cuda"

        # 组件初始化
        self.signal_encoder = SignalEncoder().to(self.device)
        self.generator = AutoregressiveGenerator(
            n_herbs=len(herb_vocab or []),
        ).to(self.device)
        self.predictor = FormulaPredictor(
            n_herbs=len(herb_vocab or []),
        ).to(self.device)
        self.discriminator = FormulaDiscriminator(
            n_herbs=len(herb_vocab or []),
        ).to(self.device)
        self.template_subsystem = TemplateSubsystem()
        self.formula_selector = FormulaSelector()

        self.herb_vocab = herb_vocab or []

    async def generate(
        self,
        target_effects: List[str],
        constraints: Optional[Dict] = None,
        template_preference: Optional[str] = None,
        n_candidates: int = 10,
        select_top_k: int = 3,
        use_rl_tuning: bool = False,
    ) -> Dict[str, Any]:
        """
        统一生成入口

        Args:
            target_effects: 目标功效列表
            constraints: 约束条件（成本上限、人群等）
            template_preference: 偏好模板名称
            n_candidates: 生成候选数
            select_top_k: 最终选择数
            use_rl_tuning: 是否启用RL调优

        Returns:
            格式化配方结果
        """
        start_time = time.perf_counter()

        # 检查组件是否初始化
        if not hasattr(self, '_initialized') or not self._initialized:
            await self._initialize()

        # Step 1: 信号编码
        signal = self.signal_encoder.encode(
            target_effects=target_effects,
            product_category=constraints.get("product_category") if constraints else None,
            target_group=constraints.get("target_group", "adult") if constraints else "adult",
            continuous_constraints={
                "max_cost": constraints.get("max_cost", 50.0) if constraints else 50.0,
                "min_efficacy": constraints.get("min_efficacy", 0.5) if constraints else 0.5,
            } if constraints else None,
        )

        # Step 2: 模板选择
        template_name = self.template_subsystem.select_template(
            target_effects=target_effects,
            preference=template_preference,
        )
        logger.info(f"[UnifiedEngine] 选择模板: {template_name or '无'}")

        # Step 3: 自回归生成（多轮采样）
        generated_formulas = []
        for _ in range(n_candidates):
            formula = self.generator.generate_with_constraints(
                signal=signal,
                herb_vocab=self.herb_vocab,
                min_herbs=3,
                max_herbs=12,
                exclude_herbs=constraints.get("exclude_herbs", []) if constraints else [],
            )
            if formula:
                # 模板干预
                if template_name:
                    formula = self.template_subsystem.apply_template(
                        [formula], template_name, mode="pre_fill"
                    )[0]
                generated_formulas.append(formula)

        # Step 4: 预测器评分
        scored_formulas = await self._score_formulas(generated_formulas)

        # Step 5: 判别器新颖性检查
        novelty_scores = await self._check_novelty(scored_formulas)

        # Step 6: 选择器优选
        candidates = self.formula_selector.select(
            scored_formulas,
            target_effects=target_effects,
            constraints=constraints,
        )

        # Step 7: 安全合规检查
        safe_candidates = await self._safety_check(candidates, constraints)

        # Step 8: 君臣佐使结构构建
        final_result = self._build_tcm_structure(safe_candidates[:select_top_k], target_effects)

        elapsed = (time.perf_counter() - start_time) * 1000
        logger.info(f"[UnifiedEngine] 生成完成: {len(final_result.get('data', []))} 味药材, {elapsed:.1f}ms")

        return final_result

    async def _initialize(self):
        """组件初始化（惰性加载）"""
        # TODO: 加载预训练权重
        self._initialized = True
        logger.info("[UnifiedEngine] 组件初始化完成")

    async def _score_formulas(
        self, formulas: List[Dict]
    ) -> List[Dict]:
        """预测器评分"""
        # TODO: 实现
        return formulas

    async def _check_novelty(
        self, formulas: List[Dict]
    ) -> List[Dict]:
        """判别器新颖性检查"""
        # TODO: 实现
        for f in formulas:
            f["novelty_score"] = 0.8  # 简化
        return formulas

    def _build_tcm_structure(
        self, candidates: List[Dict], target_effects: List[str]
    ) -> Dict:
        """君臣佐使结构构建（继承现有逻辑）"""
        if not candidates:
            return {"summary": "未生成有效配方", "data": [], "scores": {}}

        # 按综合评分排序
        sorted_candidates = sorted(
            candidates,
            key=lambda c: c.get("overall_score", 0),
            reverse=True,
        )

        best = sorted_candidates[0]
        herbs = best.get("ingredients", [])

        # 按用量降序分配君臣佐使
        sorted_herbs = sorted(herbs, key=lambda x: x.get("dosage", 0), reverse=True)
        roles = ["君", "臣", "臣", "佐", "佐", "使"]

        formula_data = []
        for i, herb in enumerate(sorted_herbs[:6]):
            role = roles[i] if i < len(roles) else "佐"
            formula_data.append({
                "role": role,
                "name": herb.get("name_cn", herb.get("id", "")),
                "dosage": f"{herb.get('dosage', 0)}g",
                "purpose": target_effects[0] if target_effects else "综合调理",
                "score": best.get("overall_score", 0),
            })

        return {
            "summary": f"已通过自回归生成 {len(formula_data)} 味药材配方方案",
            "details": f"综合评分: {best.get('overall_score', 0):.3f}",
            "data": formula_data,
            "scores": {
                "overall_score": best.get("overall_score", 0),
                "efficacy_score": best.get("efficacy_score", 0),
                "safety_score": best.get("safety_score", 0),
                "taste_score": best.get("taste_score", 0),
                "novelty_score": best.get("novelty_score", 0),
            },
            "template_used": None,
        }
```

## 六、关键技术决策

### 6.1 生成器架构选择

| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| 自回归LSTM | 专利核心，序列建模强 | 训练慢，需要大量数据 | ✅ **采用** |
| Transformer | 并行训练快，效果好 | 资源消耗大 | 备选 |
| GAN | 生成质量高 | 训练不稳定 | 不采用 |
| VAE | 隐空间平滑 | 生成质量一般 | 不采用 |

**决策理由**：
- 专利明确要求自回归生成，LSTM是标准实现
- 中药配方具有明确的序列结构（君→臣→佐→使），自回归天然适合
- 数据规模有限（~200味药材），LSTM比Transformer更经济

### 6.2 评估器与预测器的分工

| 组件 | 时机 | 目的 |
|------|------|------|
| FormulaEvaluator | 生成后 | 离线评估，最终评分 |
| FormulaPredictor | 生成中/后 | 实时反馈，引导生成 |
| HerbPeptideSynergyEvaluator | 生成后 | 肽类协同评估 |

### 6.3 数据层升级

| 现有 | 升级后 |
|------|--------|
| `_BUILTIN_HERBS` 硬编码20味 | 从TCMSP/DFBP动态加载200+味 |
| 功效评分手工标注 | 从文献/数据库自动填充 |
| 配伍禁忌28对 | 扩展至100+对（补充《本草纲目》） |
| 肽数据库未对接 | 对接PepINVERT + DFBP |

## 九、风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 训练数据不足 | 生成质量低 | 迁移学习 + 数据增强 |
| LSTM训练不稳定 | 收敛困难 | 梯度裁剪 + learning rate warmup |
| 判别器模式崩溃 | 生成多样性下降 | WGAN-GP替代标准GAN |
| 与现有系统冲突 | 回归测试失败 | 渐进式替换 + 双引擎并行 |
| 药效评估不准 | 生成配方无效 | 专家审核 + 临床验证 |
