## 四、核心能力

| 组件 | 能力 |
|------|------|
| **SignalEncoder** | 功效→36维向量（16+8+8+4） |
| **AutoregressiveGenerator** | 自回归生成3-12味药材配方 |
| **FormulaPredictor** | 7维属性预测（功效/安全/口感/成本/协同/稳定/ADMET） |
| **FormulaDiscriminator** | 新颖性检测（统计分布判别） |
| **TemplateSubsystem** | 8个经典方剂模板（四君子汤、六味地黄丸等） |
| **RLFormulaTuner** | 策略梯度调优（REINFORCE+EMA基线） |
| **FormulaSelector** | Lexicographic/Weighted/ε-Constraint 三种选择策略 |
| **UnifiedFormulaEngine** | 端到端生成流程（8步管线） |
