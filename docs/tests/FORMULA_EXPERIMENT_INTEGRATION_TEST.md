# 配方 ↔ 实验 互通测试用例

## 测试概述
验证配方管理页面与实验管理页面之间的双向互通能力。

---

## 测试用例 1: 从配方详情页 → 创建关联实验

| 步骤 | 操作 |
|------|------|
| 1 | 打开 `http://localhost:3000/formulas/1`（任意已有配方） |
| 2 | 确认页面顶部按钮栏出现 **"创建实验"** 按钮（`TestTubes` 图标） |
| 3 | 点击 **"创建实验"** |
| 4 | 验证跳转到 `/experiments/new?formula_id=1` |
| 5 | 验证"关联配方"区域自动显示已关联配方 ID: 1 |
| 6 | 填写实验标题、选择实验类型、填写目标 |
| 7 | 点击 **"创建实验"** |
| 8 | 验证跳转到 `/experiments/{new_id}` 详情页 |
| 9 | 验证详情页"关联配方"链接指向原配方 |

**预期结果**: 实验创建成功，`formula_id` 正确关联。

## 端到端流程图

```
配方详情页 (/formulas/1)
    │
    ├─→ [创建实验] ──→ 新建实验页 (/experiments/new?formula_id=1)
    │                    ├─→ 自动关联配方 ID: 1
    │                    └─→ 创建成功 ──→ 实验详情页
    │
    └─→ [关联实验列表] ──→ 显示已关联实验
                            ├─→ 点击实验 ──→ 实验详情页
                            └─→ 空状态 ──→ [从此配方创建实验]

实验详情页 (/experiments/1)
    │
    ├─→ [关联配方] ──→ 配方详情页 (/formulas/1)
    │
    ├─→ [导出数据] ──→ CSV 下载
    │
    └─→ [编辑] ──→ 编辑页 ──→ 保存 ──→ 实验详情页
```

---

## 已知限制

1. 实验列表 API 需要后端支持 `formula_id` 查询参数（已验证后端支持）
2. 实验详情页的进度计算基于 `start_date` 和 `end_date`，无日期时给默认 50%
3. 关联实验列表在前端缓存 60 秒（staleTime）
4. 材料和设备的后端字段 `materials`/`equipment` 已在后端 schema 中定义

---

## 运行测试

1. 启动后端: `cd backend && uvicorn app.main:app --reload`
2. 启动前端: `cd frontend && npm run dev`
3. 按顺序执行上述测试用例
4. 每个用例验证"预期结果"列
