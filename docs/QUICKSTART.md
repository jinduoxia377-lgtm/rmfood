## 快速启动

### 方式一：本地开发环境（推荐）

#### 前置条件
- Node.js >= 18.x
- Python >= 3.11
- Git

#### 步骤 1: 克隆项目
```bash
git clone https://github.com/your-org/rmfood-platform.git
cd RMFOOD配方平台
```

#### 步骤 2: 启动后端服务
```bash
cd backend

# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 初始化数据库
python migrate.py init

# 启动开发服务器
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

> **提示**: 首次启动会自动生成管理员密码，请查看控制台输出。

#### 步骤 3: 启动前端服务
```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:3000 即可使用！

### 方式二：Docker 一键部署

```bash
# 构建并启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f backend frontend
```

服务地址：
- 前端: http://localhost:3000
- 后端 API: http://localhost:8000
- API 文档: http://localhost:8000/docs

## 首次登录

### 默认管理员账号

| 字段 | 值 |
|------|-----|
| 用户名 | `admin` |
| 密码 | *见控制台输出*（首次启动时自动生成） |

2. 进入登录页面
3. 输入管理员账号密码

- 最小长度: 8 位（开发）/ 12 位（生产）

  - 数字 (0-9)
  - 特殊字符 (!@#$%^&*)

## 核心功能导览

### 🎯 仪表盘 (Dashboard)

### 📝 配方管理 (Formula Management)

#### 创建新配方

1. 点击左侧菜单 "配方管理" → "新建配方"
2. 填写基本信息:
   - **配方名称**: 唯一标识符
   - **描述**: 详细说明用途和目标
   - **分类**: 选择合适的分类标签
3. 添加原料成分:
   - 从知识库选择或手动输入
   - 设置每种成分的用量和单位
4. 配置优化参数（可选）:
   - 目标功效类型
   - 成本预算范围
   - 安全性约束条件
5. 点击"保存草稿"或"提交审核"

#### 版本控制

每次保存都会创建新版本：
- **版本历史**: 查看所有修改记录
- **版本对比**: 并排比较两个版本的差异
- **版本回滚**: 恢复到历史版本

#### 配方状态流转

```
草稿(Draft) → 待审核(Pending) → 已发布(Published) / 已拒绝(Rejected)
    ↑                                    ↓
    └──────────── 退回修改 ←───────────┘
```

### 🔬 实验管理 (Experiment)

#### 创建实验

1. 进入"实验管理" → "新建实验"
2. 关联目标配方（可选）
3. 设置实验参数:

4. 录入数据点:

#### 数据分析

- 自动生成统计图表
- 趋势分析报告
- 异常值检测与标记

### 🤖 AI 智能助手 (AI Assistant)

#### AI 配方生成

1. 进入"AI助手"页面
2. 选择生成模式:
   - **智能推荐**: 根据需求描述自动生成候选方案
   - **神经网络生成**: 使用深度学习模型优化
   - **模板匹配**: 基于历史成功案例
3. 输入需求参数:
   ```
   目标功效: 降血糖
   目标人群: 中老年糖尿病患者
   剂型: 固体饮料
   口感偏好: 清淡微甜
   成本上限: ¥15/份
   ```
4. 点击"开始生成"
5. 查看多个候选方案并进行对比
6. 使用"多目标优化"调整方案

#### AI 功能矩阵

| 功能 | 描述 | 适用场景 |
|------|------|----------|
| 配方生成 | 自动设计初始配方 | 新产品研发初期 |
| 多目标优化 | 功效/口感/成本平衡 | 方案精细化调整 |
| 安全性检查 | 成分相互作用检测 | 发布前必检 |
| 稳定性预测 | 保质期预估 | 包装和存储规划 |
| 协同效应分析 | 成分协同增效评估 | 功效增强研究 |
| 口感预测 | 风味轮廓预测 | 感官评价辅助 |
| 学术报告 | 自动撰写研究报告 | 论文和专利申请 |

### 🔄 工作流引擎 (Workflow)

#### 可视化编辑器

1. 进入"工作流管理" → "新建工作流"
2. 选择模板或从零开始:
   - **AI配方生成流水线**
   - **配方审核流程**
   - **数据同步流水线**
3. 拖拽节点构建流程:
   - 任务节点（矩形）
   - 条件判断（菱形）
   - 开始/结束（圆角矩形）
4. 连接节点定义流程走向
5. 配置每个节点的详细参数
6. 保存并执行工作流

#### 工作流模板

| 模板 | 用途 | 预计耗时 |
|------|------|----------|
| AI配方生成 | 从需求到候选方案 | 5-15分钟 |
| 配方审核 | 标准化审批流程 | 1-3天 |
| 数据同步 | 外部数据库更新 | 30-60分钟 |
| 批量分析 | 批量安全性检查 | 10-30分钟 |

### 📚 知识库 (Knowledge Database)

#### 中药材查询 (TCMSP)

- **搜索方式**: 名称、拼音、拉丁名、功效关键词
- **数据字段**: 性味归经、功能主治、化学成分、现代研究
- **来源对接**: TCMSP (Traditional Chinese Medicine Systems Pharmacology Database)

#### 生物活性肽 (DFBP)

- **序列检索**: FASTA格式、BLAST同源性比对
- **活性类型**: ACE抑制、抗氧化、抗菌、抗炎等
- **结构信息**: 分子量、等电点、疏水性

#### 知识图谱

- 可视化展示"成分-靶点-疾病"关系网络
- 支持交互式探索和路径发现

## 故障排除

### 常见问题

#### Q: 登录失败提示"账号已锁定"

**原因**: 连续5次输入错误密码导致临时锁定

**解决方法**:
1. 等待15分钟后自动解锁
2. 或联系管理员手动解锁（需要ADMIN角色）

**预防措施**:
- 使用密码管理器避免忘记密码
- 开启双因素认证(2FA)（即将推出）

---

#### Q: 页面加载缓慢

**可能原因及解决方案**:

| 原因 | 解决方案 |
|------|----------|
| 网络延迟 | 检查网络连接，尝试刷新 |
| 后端未启动 | 确认 `uvicorn` 服务运行正常 |
| 数据库锁等待 | 避免长时间占用事务 |
| 缓存过期 | 等待缓存重建（通常<30秒） |

**诊断命令**:
```bash
# 检查后端健康状态
curl http://localhost:8000/health

# 检查前端构建状态
npm run build  # 查看是否有编译错误
```

---

#### Q: AI生成无响应

**排查步骤**:
1. 检查网络连接（AI服务需联网）
2. 查看浏览器控制台是否有错误信息
3. 确认API密钥配置正确
4. 尝试简化输入参数重新生成

**联系支持**:
如问题持续存在，请联系技术支持并提供:
- 操作截图
- 浏览器控制台错误信息
- 具体的输入参数

---

#### Q: 文件上传失败

**限制说明**:
- 单文件最大: 10MB
- 允许格式: PDF, DOC, DOCX, XLS, XLSX, PNG, JPG, JPEG, WEBP
- 总存储空间: 取决于服务器配置

**解决方案**:
1. 检查文件大小和格式
2. 压缩大文件后再上传
3. 联系管理员增加存储配额
