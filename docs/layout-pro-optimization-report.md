## 十、技术亮点

### 10.1 架构优势

```
┌─────────────────────────────────────────┐
│           页面层 (Pages)                │
│  • 首页 - 标准化布局                    │

              ↓
┌─────────────────────────────────────────┐
│         组件层 (Components)             │
│  • Icon - 内联SVG路径系统               │
│  • NavBar - 统一导航栏                   │
│  • Button - 标准化按钮                   │
│  • Card - 卡片容器                       │

│  • icons.js - 图标数据                  │
└─────────────────────────────────────────┘
```

### 10.2 设计原则

1. **标准化** - 所有数值使用CSS变量，一处修改全局生效
2. **层次化** - 清晰的视觉层次，主次分明
3. **一致性** - 统一的间距、字体、色彩系统
4. **可访问性** - 支持深色模式和减少动画偏好
5. **响应式** - 适配不同屏幕尺寸和安全区域
