## 三、RMFOOD小程序配料表分析功能设计

### 3.1 功能流程

```
用户扫描/输入配料表
        ↓
┌─────────────────────┐
│  成分识别与解析      │
│  • OCR识别文字       │
│  • 成分名称标准化    │
│  • 成分分类标注      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  成分分析引擎        │
│  • 营养数据库匹配    │
│  • 添加剂识别        │
│  • 过敏原检测        │
│  • 药食同源成分识别  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  健康评估算法        │
│  • Nutri-Score计算   │
│  • NOVA分组判断      │
│  • 添加剂风险评估    │
│  • 药食同源价值评估  │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│  结果展示            │
│  • 营养成分表        │
│  • 配料分解          │
│  • 健康评分          │
│  • 成分标签          │
│  • 改进建议          │
└─────────────────────┘
```

### 5.3 分析算法

#### 5.3.1 Nutri-Score计算算法

```python
def calculate_nutri_score(nutrition_data: Dict) -> str:
    """
    计算Nutri-Score（法国营养评分系统）
    
    评分规则：
    - 负分项（不利健康）：能量、饱和脂肪、糖、钠
    - 正分项（有利健康）：蛋白质、膳食纤维、水果蔬菜
    
    返回：A/B/C/D/E
    """
    
    # 负分计算
    negative_points = 0
    negative_points += min(nutrition_data['energy'] / 335 * 10, 10)  # 能量
    negative_points += min(nutrition_data['saturated_fat'] / 10 * 10, 10)  # 饱和脂肪
    negative_points += min(nutrition_data['sugar'] / 45 * 10, 10)  # 糖
    negative_points += min(nutrition_data['sodium'] / 800 * 10, 10)  # 钠
    
    # 正分计算
    positive_points = 0
    positive_points += min(nutrition_data['protein'] / 50 * 10, 10)  # 蛋白质
    positive_points += min(nutrition_data['fiber'] / 15 * 10, 10)  # 膳食纤维
    positive_points += nutrition_data['fruit_veg'] * 5  # 水果蔬菜
    
    # 最终得分
    total_score = negative_points - positive_points
    
    # 评级
    if total_score <= 2:
        return 'A'  # ⭐⭐⭐⭐⭐ 优秀
    elif total_score <= 10:
        return 'B'  # ⭐⭐⭐⭐ 良好
    elif total_score <= 18:
        return 'C'  # ⭐⭐⭐ 一般
    elif total_score <= 28:
        return 'D'  # ⭐⭐ 较差
    else:
        return 'E'  # ⭐ 差
```

#### 5.3.2 NOVA分组判断算法

```python
def classify_nova_group(ingredients: List[Ingredient]) -> int:
    """
    判断NOVA分组
    
    规则：
    - 1组：无添加剂、无加工成分
    - 2组：仅含加工原料（油、糖、盐）
    - 3组：有添加剂、有限加工
    - 4组：有大量添加剂、超加工
    """
    
    additives_count = len([i for i in ingredients if i.category == 'additive'])
    processed_ingredients = len([i for i in ingredients if i.nova_group >= 3])
    
    if additives_count == 0 and processed_ingredients == 0:
        return 1  # 未加工或最低限度加工
    elif additives_count == 0 and processed_ingredients <= 2:
        return 2  # 加工烹饪原料
    elif additives_count <= 3:
        return 3  # 加工食品
    else:
        return 4  # 超加工食品
```
