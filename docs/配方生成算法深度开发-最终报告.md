## 六、技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    配方生成系统 v3.0                          │
├─────────────────────────────────────────────────────────────┤
│  FormulaDesigner（总控制器）                                  │
│  ├── use_new_engine=True → UnifiedFormulaEngine             │

│  │   ├── TemplateSubsystem → 经典方剂先验                    │

│  │   ├── FormulaPredictor → 实时评分                         │
│  │   ├── FormulaDiscriminator → 新颖性检查                   │
│  │   ├── RLFormulaTuner → 策略梯度调优                       │
│  │   ├── FormulaSelector → 优先级选择                        │
│  │   └── SafetyChecker → 安全合规                            │
│  └── use_new_engine=False → 传统引擎（贝叶斯/NSGA-II）       │
└─────────────────────────────────────────────────────────────┘
```
