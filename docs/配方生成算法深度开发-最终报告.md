## 四、API 端点

### 新增端点：`POST /generate/v2`

```bash
curl -X POST http://localhost:8000/ai/generate/v2 \
  -H "Content-Type: application/json" \
  -d '{
    "target_effects": ["补气", "养血"],
    "use_new_engine": true,
    "template": "四君子汤",
    "n_candidates": 10,
    "select_top_k": 3,
    "use_rl_tuning": false
```
