技术亮点

🔐 安全认证

AES加密存储Token，自动刷新机制，401自动跳转登录

⚡ 流式输出

fetch API + ReadableStream，打字机效果，支持降级轮询

📦 分包加载

按模块拆分，按需下载，主包<2MB，秒开体验

💾 离线缓存

本地Storage缓存，弱网可用，网络恢复自动同步

📷 拍照识别

微信OCR API，自动识别配料表，支持手动补充

📊 GB 28050标准

符合国家营养标签标准，能量校验，营养声称检测
