## 一、产品定位与核心价值

### 1.1 产品定位

**RMFOOD小程序**是「药食同源配方平台」的移动端入口，为普通用户提供：
- 🧪 **配料表分析** - 拍照识别食品配料，评估健康价值
- 💬 **AI配方顾问** - 智能对话，获取个性化食疗建议
- 📋 **配方管理** - 收藏、分享、对比优质配方

### 1.2 核心价值

| 用户群体 | 核心需求 | 解决方案 |
|---------|---------|---------|
| 养生爱好者 | "这个食品配料健康吗？" | 配料表分析 + 营养评估 |
| 亚健康人群 | "我该怎么调理？" | AI配方顾问 + 体质诊断 |
| 专业营养师 | "如何推荐配方？" | 配方库 + 科学机理 |
| 普通消费者 | "怎么选择食品？" | 配料识别 + 安全审查 |

## 十、设计原则

### 10.1 视觉设计原则

| 原则 | 说明 |
|------|------|
| 绿色主题 | 深绿#2D5A3D为主色，呼应药食同源 |
| 简洁清晰 | 信息层级分明，避免视觉噪音 |
| 圆角卡片 | 现代感设计，提升亲和力 |
| 大字体 | 适老化设计，易于阅读 |

### 10.2 交互设计原则

| 原则 | 说明 |
|------|------|
| 一键操作 | 核心功能一键可达 |
| 即时反馈 | 操作后有明确反馈 |
| 防误触 | 重要操作二次确认 |
