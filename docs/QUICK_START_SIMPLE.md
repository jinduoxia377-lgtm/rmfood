```
访问 → 输入账号密码 → 点击登录
```

### 第二步：创建配方
```
左侧菜单 → 智能配方 → 引导模式 → 选择功效 → 下一步
```

```
查看分析结果 → 点击导出 → 选择格式下载
```

## ⚡ 常用操作

### 创建配方
1. 点击「智能配方」
2. 选择「引导模式」
3. 选择功效目标（可多选）
4. 调整成分比例
5. 查看分析结果
6. 导出报告

### 搜索功能
- 在顶部搜索框输入关键词
- 支持：配方名称、成分名称、功效

### 数据导出
- **PDF**: 完整报告，适合打印
- **Excel**: 可编辑表格
- **JSON**: 开发者数据

## 💡 新手提示

1. **推荐使用引导模式**：4步完成配方设计
2. **功效选择**：建议选2-3个相关功效
3. **保存草稿**：不确定时先保存
4. **查看帮助**：遇到问题点击问号图标

## ❓ 常见问题

**Q: 登录失败怎么办？**
- 检查账号密码是否正确
- 确认后端服务已启动

**Q: 配方生成慢？**
- 网络延迟可能导致
- 尝试简化功效选择
