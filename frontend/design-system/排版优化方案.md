# RMFOOD 项目排版优化方案

## 一、排版优化核心原则

### 1.1 视觉层次结构

| 层级 | 元素类型 | 字号 | 字重 | 颜色 | 行高 |
|------|----------|------|------|------|------|
| **L1 标题** | 页面主标题 | 28-32px | 700 | --text-primary | 1.2 |
| **L2 副标题** | 区块标题 | 20-24px | 600 | --text-primary | 1.3 |
| **L3 小标题** | 卡片标题 | 16-18px | 600 | --text-primary | 1.4 |
| **L4 标签** | 字段标签 | 13-14px | 500 | --text-secondary | 1.4 |
| **L5 正文** | 内容文字 | 14-15px | 400 | --text-secondary | 1.6 |
| **L6 辅助** | 提示文字 | 12-13px | 400 | --text-muted | 1.5 |

### 1.2 图标与文字比例关系

| 图标尺寸 | 适用文字尺寸 | 图标-文字间距 | 使用场景 |
|----------|-------------|---------------|----------|
| 12px | 11-12px | 4px | 标签内小图标 |
| 14px | 12-13px | 6px | 辅助说明 |
| 16px | 13-14px | 6-8px | 表单标签、列表项 |
| 18px | 14-16px | 8px | 按钮、导航 |
| 20px | 16-18px | 10px | 卡片图标 |
| 24px | 18-24px | 12px | 区块图标 |

## 二、图标系统规范

### 2.1 图标尺寸层级

```css
/* 图标尺寸系统 */
.icon-xs { width: 12px; height: 12px; }  /* 极小图标，用于紧凑布局 */
.icon-sm { width: 14px; height: 14px; }  /* 小图标，辅助信息 */
.icon-md { width: 16px; height: 16px; }  /* 中等图标，标准使用 */
.icon-lg { width: 18px; height: 18px; }  /* 大图标，强调使用 */
.icon-xl { width: 20px; height: 20px; }  /* 特大图标，装饰使用 */
.icon-2xl { width: 24px; height: 24px; } /* 超大图标，区块图标 */

/* 图标与文字对齐 */
.icon-align-baseline { vertical-align: baseline; }  /* 文字基线对齐 */
.icon-align-middle { vertical-align: middle; }      /* 垂直居中 */
.icon-align-text-top { vertical-align: text-top; }   /* 文字顶部对齐 */
```

### 2.2 图标与文字组合规范

```css
/* 组合：图标 + 文字 */
.icon-text组合 {
  display: inline-flex;
  align-items: center;
  gap: 6px;  /* 图标与文字间距 */
}

/* 文字在上，图标的垂直对齐 */
.icon-text-vertical {
  display: inline-flex;
  flex-direction: column;
  align-items: center;
  gap: 4px;
}

/* 图标在左，文字在右（标准导航） */
.icon-leading {
  display: flex;
  align-items: center;
  gap: 10px;
}

.icon-leading .icon {
  flex-shrink: 0;  /* 防止图标被压缩 */

/* 图标在右，文字在左 */
.icon-trailing {
  display: flex;
  align-items: center;
  gap: 8px;
  flex-direction: row-reverse;
}
```

## 四、响应式断点系统

### 4.1 断点定义

| 断点 | 宽度 | 设备类型 | 布局策略 |
|------|------|----------|----------|
| XS | < 480px | 超小屏手机 | 单列，简单布局 |
| SM | 480-639px | 手机 | 单列，基础布局 |
| MD | 640-767px | 大手机/小平板 | 双列，可折叠导航 |
| LG | 768-1023px | 平板 | 双列，侧边栏 |
| XL | 1024-1279px | 小桌面 | 三列，固定侧边栏 |
| 2XL | ≥ 1280px | 桌面 | 多列，完整布局 |

## 八、优化效果对比

### 8.1 优化前后对比

| 元素 | 优化前 | 优化后 | 改进效果 |
|------|--------|--------|----------|
| **标签页间距** | 4px | 8px | 视觉更舒适，减少拥挤感 |
| **按钮图标间距** | 4px | 8px | 图标与文字关系更协调 |
| **导航图标尺寸** | 不统一 | 18px | 所有导航图标尺寸一致 |
| **标题行高** | 1.2 | 1.3-1.4 | 文字呼吸感更强 |
| **正文字号** | 14px | 15px | 阅读更舒适 |
| **正文字重** | 400 | 400 | 保持清晰可读 |
| **段落间距** | 1em | 1.7em | 段落层次更清晰 |

### 8.2 视觉层级优化

**优化前问题**：
- 视觉层次不清晰
- 图标与文字关系混乱
- 间距不统一
- 响应式表现差

**优化后效果**：
- 清晰的视觉层次结构
- 图标与文字比例协调
- 间距系统统一
- 完美的响应式表现
