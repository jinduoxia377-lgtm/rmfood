# 登录功能模块技术文档

## 1. 功能概述

登录功能模块是 RMFOOD 配方设计平台的核心认证系统，提供了完整的用户身份验证流程，包括：

- 用户账号密码登录
- 前端实时表单验证
- 后端安全验证
- 登录状态管理
- 记住登录状态功能
- 密码找回功能
- 第三方登录集成
- 登录失败处理机制
- 友好的错误提示

## 2. 技术实现

### 2.1 前端实现

#### 2.1.1 登录页面 (`LoginPage.tsx`)

- **布局**：采用左右分栏设计，左侧为品牌展示区，右侧为登录表单区
- **主题模式适配**：左侧区域背景颜色与系统主题模式(明/暗模式)动态关联，实现无缝的主题过渡效果
- **表单验证**：实现了实时表单验证，包括用户名和密码的长度验证
- **记住登录状态**：通过 localStorage 存储用户选择
- **第三方登录**：集成了微信、QQ、GitHub 等第三方登录选项
- **错误处理**：显示不同类型的错误提示，包括表单验证错误和登录失败错误
- **视觉效果**：添加了生物元素动态效果，包括分子纹理背景的浮动动画和品牌元素的淡入动画
- **可访问性**：添加了完整的 ARIA 属性，确保符合 WCAG 2.1 AA 级标准
- **性能优化**：使用 useCallback 优化事件处理函数，减少不必要的重渲染
- **响应式设计**：针对桌面端、平板端和移动端进行了详细的布局优化

#### 2.1.2 密码找回页面 (`ForgotPasswordPage.tsx`)

- **邮箱验证**：用户输入邮箱地址，系统发送密码重置邮件
- **状态反馈**：提供发送成功和失败的状态反馈
- **流程引导**：引导用户完成密码重置流程

#### 2.1.3 状态管理 (`useAuthStore`)

- 使用 Zustand 管理认证状态
- 支持 JWT 令牌存储和刷新
- 提供登录、登出、获取用户信息等方法

### 2.2 后端实现

#### 2.2.1 认证 API (`auth.py`)

- **登录接口**：`POST /auth/login` - 验证用户名密码，返回 JWT 令牌
- **刷新令牌**：`POST /auth/refresh` - 使用刷新令牌获取新的访问令牌
- **获取用户信息**：`GET /auth/me` - 获取当前登录用户信息
- **密码找回**：`POST /auth/forgot-password` - 发送密码重置邮件
- **重置密码**：`POST /auth/reset-password` - 使用令牌重置密码

#### 2.2.2 认证服务 (`AuthService`)

- **密码哈希**：使用 bcrypt 进行密码加密
- **JWT 令牌**：生成和验证 JWT 令牌
- **安全验证**：验证用户凭据，处理账户状态
- **密码重置**：生成密码重置令牌，处理密码重置逻辑

## 3. 功能特性

### 3.1 前端表单验证

- **实时验证**：输入时立即验证，提供即时反馈
- **错误提示**：清晰的错误提示信息
- **表单状态**：正确处理表单的各种状态（空值、无效值、有效值）

### 3.2 登录状态管理

- **JWT 令牌**：使用 JWT 进行身份验证
- **持久化存储**：令牌存储在 localStorage 中
- **自动刷新**：支持令牌自动刷新
- **记住登录**：可选的记住登录状态功能

### 3.3 密码找回功能

- **邮箱验证**：通过邮箱发送密码重置链接
- **安全令牌**：使用安全的密码重置令牌
- **有效期**：重置令牌有 24 小时有效期
- **流程安全**：即使邮箱不存在也返回成功，避免信息泄露

### 3.4 第三方登录

- **多平台支持**：集成微信、QQ、GitHub 登录
- **统一接口**：提供统一的登录接口
- **用户体验**：简化登录流程，提升用户体验

### 3.5 错误处理

- **友好提示**：清晰、友好的错误提示信息
- **错误分类**：区分不同类型的错误（网络错误、验证错误、服务器错误）
- **状态反馈**：提供加载状态和错误状态的视觉反馈

- JWT (身份验证)
- Python

## 5. API 接口

### 5.1 登录接口

**POST /auth/login**

- **请求体**：
  ```json
  {
    "username": "admin",
    "password": "admin123"
  }
  ```

- **响应**：
  ```json
  {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
  ```

### 5.2 密码找回接口

**POST /auth/forgot-password**

- **请求体**：
  ```json
  {
    "email": "user@example.com"
  }
  ```

- **响应**：
  ```json
  {
    "message": "密码重置邮件已发送"
  }
  ```

### 5.3 重置密码接口

**POST /auth/reset-password**

- **请求体**：
  ```json
  {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "new_password": "newpassword123"
  }
  ```

- **响应**：
  ```json
  {
    "message": "密码重置成功"
  }
  ```

## 6. 安全措施

- **密码加密**：使用 bcrypt 进行密码哈希
- **JWT 令牌**：使用安全的 JWT 令牌进行身份验证
- **令牌过期**：访问令牌和刷新令牌都有过期时间
- **CSRF 保护**：实现 CSRF 保护机制
- **登录尝试限制**：防止暴力破解攻击
- **敏感信息保护**：不在前端存储敏感信息

## 7. 响应式设计

- **桌面端**：左右分栏布局，最佳显示效果
- **平板端**：自动调整布局，适应中等屏幕
- **移动端**：单栏布局，优化触摸操作
