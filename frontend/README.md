# RMFOOD 配方设计平台 - 前端

## 技术栈

- React 19 + TypeScript
- Vite 8 (构建工具)
- Tailwind CSS 4 (样式)
- React Router 7 (路由)
- React Query v5 (数据获取)
- Zustand (状态管理)
- Axios (HTTP 客户端)
- Lucide React (图标)
- Recharts (图表)

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 构建生产版本

```bash
npm run build
```

## 功能模块

- 登录/注册/令牌管理
- 仪表盘 (统计概览 + 快捷入口)
- 配方管理 (列表/详情/新建/编辑/审核)
- 实验管理 (列表/详情/状态流转)
- AI 成分推荐 (基于功效标签)
