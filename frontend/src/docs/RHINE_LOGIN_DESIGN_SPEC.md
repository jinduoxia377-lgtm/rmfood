# 莱茵分子 (Rhine Molecular) — 登录页面设计规范

**版本**: v1.0.0  
**设计框架**: UI/UX Pro Max  
**更新日期**: 2026-06-04  
**适用技术栈**: React 19 + TypeScript 6 + Canvas API + CSS 3D Transforms

---

## 1. 设计理念

### 品牌定位
莱茵分子是专注于**分子生物学与功能性食品研发**的前沿生物技术公司。设计需要在**科学严谨性**与**技术创新感**之间取得平衡。

### 设计关键词
- **分子美学**: DNA 双螺旋、分子粒子、六边形晶格
- **深空实验室**: 暗色基底 + 生物荧光辉光
- **精密科学**: 数据可视化级别的精确度

### 情感目标
1. **震撼** — 第一眼感受到生物技术的前沿性
2. **信任** — 科学精确性传达专业可靠
3. **好奇** — 交互细节激发探索欲

## 5. 组件规范

### 粒子画布
- 粒子数量: 150 (桌面) / 80 (平板) / 40 (手机)
- 连接距离阈值: 80px
- 鼠标引力范围: 150px
- 帧率目标: 60fps

### DNA 螺旋
- 螺旋圈数: 8 圈
- 每圈节点: 10 对碱基
- 旋转周期: 60s (完整一圈)
- 透视距离: 800px

### 玻璃卡片
- 背景: `rgba(17, 24, 39, 0.7)`
- 模糊: `blur(24px) saturate(180%)`
- 边框: `1px solid rgba(0, 201, 167, 0.15)`
- 最大宽度: 440px
- 输入框高度: 48px
