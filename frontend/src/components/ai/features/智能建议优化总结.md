#### 核心组件：
- **IntelligentKeywordExtractor**: 智能关键词提取器
- **SemanticSimilarityCalculator**: 语义相似度计算器
- **ContextAwarenessEngine**: 上下文感知引擎
- **PersonalizationEngine**: 个性化引擎（可选）
- **IntelligentSuggestionGenerator**: 主智能建议生成器

#### 关键特性：
```typescript
// 实时响应配置
const REAL_TIME_TIMEOUT_MS = 400; // 确保500ms内完成更新

  keywordMatch * 0.35 + // 关键词匹配权重
  domainMatch * 0.25; // 领域匹配权重
```

### 4. **🔧 集成实现**

#### useChatInputState.ts 更新：
```typescript
// 智能建议生成器单例
const getIntelligentSuggestionGenerator = useCallback(() => {
  if (!window.__intelligentSuggestionGenerator) {
    window.__intelligentSuggestionGenerator = new IntelligentSuggestionGenerator({ timeout: 400 });
  }
  return window.__intelligentSuggestionGenerator;
}, []);

// 生成流程
1. 提取实体 (EntityExtractor)
2. 分类意图 (IntentClassifier)
3. 构建上下文 (GenerationContext)
4. 生成建议 (generateSuggestions)
5. 回退机制 (Fallback to old engine)
```
