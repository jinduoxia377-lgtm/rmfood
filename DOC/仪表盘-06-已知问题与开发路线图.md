## 1. P0 问题（立即修复）

### P0-01 StatsCards 未接收 statIndex（C-01）
- **症状**：`DashboardPage.renderCard` 通过 `CARD_COMPONENTS` 展开 props，`StatsCards` 需要的 `statIndex` 未注入 → 图标回退 FlaskConical、标签为空。
- **修复**：`renderCard` 中 `if (statIndexMap[card.type] !== undefined)` 分支增加 `props.statIndex = idx`；或 StatsCards 改为从 `card.type` 派生（更内聚，推荐）。
- **回归**：4 个统计卡图标/标签与 `statIndexMap` 一一对应。

### P0-02 TemplateManager 初始化误用 useState（L-04）
- **症状**：`useState(() => { ... setTemplates(...) })` —— 惰性初始值函数体只在首次渲染执行且调用 setTemplates 于渲染期（React 告警 + 逻辑无效），模板列表挂载时不会从 localStorage 读取。
- **修复**：改 `useEffect`（挂载读取 `rmfood_dashboard_templates`）+ 初始 `useState<DashboardTemplate[]>([])`。

### P0-03 KPIDashboard 进度条单位混用（A-01）
- **症状**：`current` 已是百分比（0-100），进度条宽度却算 `(current/target)*100` → current=85/target=85 时宽度显示 8500%（被 min(100) 钳位后「达标」恒亮）。
- **修复**：`percent = Math.min(100, Math.max(0, (kpi.current / kpi.target) * 100))` → `kpi.current / kpi.target * 100` 当两者同量纲时，进度 = current/target（比例），达标阈值 isOnTrack: current >= target*0.9。

### P0-04 WebSocket on/emit 空壳（R-01）
- **症状**：`on(event, handler)` 只登记日志、`emit` 只写日志 → `user_status`、`connected`、`reconnect_attempt` 等事件**无实际分发**；TeamOnlineStatus 的 WS 实时路径不生效。
- **修复**：`WebSocketService` 增加 `private eventHandlers: Map<string, Set<Handler>>`；`emit` 遍历对应 handler；`on` 返回取消函数（移除 handler）。回归：WS 连接后 15s 内至少一次 `user_status` 事件到达（无真实事件时由服务端 heartbeat 事件替代验证）。

## 6. 分阶段开发计划

### Phase 1：稳定性修复（1-2 天，P0 全量）
1. P0-01：StatsCards statIndex 注入（renderCard 或卡片内派生）
2. P0-02：TemplateManager useEffect 初始化修复
3. P0-03：KPIDashboard 百分比口径修正 + 单测
4. P0-04：WebSocketService 事件表实现（on/emit 真实分发）
5. 回归：仪表盘首屏 4 卡片图标文案、AI 卡片进度条、WS 连接后 user_status 日志

### Phase 2：数据链路闭环（1 周，P1 全量）
1. 后端：`/trends` 聚合查询重写（P1-12）+ review-queue JOIN（API-02）
2. 通知中心接后端（R-02）+ 共享真实 user id（L-06）
3. AI 面板：mock 标识（A-04）+ 推荐跳转（A-03）+ queryKey 去重（API-03）
4. 布局：预设替换语义（L-01）+ 列/间距持久化（L-02）
5. ChangeHistory 接 audit log（R-04）

### Phase 3：智能化与协作（2-3 周，P1 剩余 + P2）
1. `/ai/predict/trends` 真实模型 + 前端降级策略
2. 团队共享后端持久化（team_router 已有端点）+ WS 团队通知频道
3. 导出事件订阅（API-04）、AI 请求缓存（A-05）
4. QuickActions Modal 化（C-04）

### Phase 4：增强（持续，P3）
1. 趋势周期切换器、用户角色分布卡、移动端适配、列表「查看全部」统一
