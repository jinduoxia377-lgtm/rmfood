Section 09

关键页面设计

9.1 登录页
布局: 左60%品牌插图(知识图谱动画) + 右40%登录表单
组件: Logo · Input×2 · 记住登录 · OAuth社交按钮 · 2FA弹窗
特效: 背景图谱节点缓慢漂浮 · 登录成功粒子扩散
9.2 配方编辑器 最复杂
布局: 三栏 — 成分浏览器(280px) + 配方画布 + AI面板(320px)
左栏: 搜索/过滤 · 分类树(中药/多肽/化合物) · 拖拽添加
中栏: 成分卡片+剂量滑块 · 组成饼图 · 状态栏
右栏: FormulaGPT对话 · SynergyNet评分 · SafetyChecker告警
9.3 知识图谱
布局: 全屏沉浸式 · 3D/2D切换
组件: 左侧搜索/筛选/图例 · 底部抽屉节点详情 · 右下角小地图
交互: 双击展开关联 · 框选多节点 · 右键上下文菜单
9.4 AI工作台
布局: 顶部模型选择卡(6模型) + 中部交互区 + 右侧历史面板
组件: 模型卡片(图标+名称+状态) · 参数表单 · WS状态灯
特效: 流式结果打字机动效 · 进度粒子环
9.5 审核中心
布局: Kanban看板 — PENDING | IN_REVIEW | APPROVED | REJECTED
卡片: 配方摘要 · 风险评分Badge · 审核员头像
交互: 拖拽切换状态 · 批量操作 · 侧拉详情面板
9.6 仪表盘
布局: 可定制Widget网格(react-grid-layout)
组件: 统计卡 · 趋势图 · 活动流 · 快捷入口
交互: 拖拽排列 · 角色默认布局 · Widget目录弹窗

设计Token与开发交付

Token层级结构

/* Global */
color.green.600 = #059669
color.blue.600 = #2563eb
/* Alias */
color.brand.primary = {color.green.600}
color.brand.ai = {color.purple.600}
/* Component */
button.primary.bg = {color.brand.primary}
button.ai.bg = gradient({color.brand.ai}, {color.brand.info})
