GA(遗传算法)-LP(线性线性规划) 混合食品配方算法架构框架

(GA-LP 混合架构)的核心逻辑是“外层 GA 选定原料组合，内层 LP 求解精确配比”。其标准执行框架可分为以下五个核心步骤：

[开始：配置目标] ➔ [GA 种群初始化: 生成原料组合编码]
                          │
                          ▼
             ┌───► [GA 选择、交叉、变异]
             │            │
             │            ▼
             │   [内层 LP 求解器：输入当前原料组合]
             │            │
             │            ├───► 无法满足硬约束？ ➔ 赋予极低适应度(淘汰)
             │            │
             │            ▼ 满足硬约束
             │   [输出：最优配比、最低成本、营养矩阵]
             │            │
             │            ▼
             │   [风味/工艺 AI 预测模型：评估口感、质构等]
             │            │
             │            ▼
             │   [计算综合适应度 (Fitness)]
             │            │
             └────────────┴───► 未达到终止条件？
                          │
                          ▼ 达到终止条件
                 [输出：生产级最优食品配方]

一、 核心输入数据（Data Inputs）
1.原料数据库：每种原料的单位成本、营养成分（蛋白质、脂肪、碳水、钠等）、理化特性限值。

2.约束条件表：
2.1硬约束（线性）：法规或产品定位要求的营养指标上下限（如：蛋白质 \(\ge 12\%\)，脂肪 \(\le 5\%\)）。
2.2软约束（非线性）：风味配比限制（如：某种香精比例不能超过固定值的非线性关系）。
2.3风味/质构评估器：基于实验历史数据训练的机器学习模型（如：输入原料配比 \(\rightarrow \) 预测口感得分）。

二、 外层：遗传算法（GA）逻辑 —— 决定“用不用”
1.染色体编码：使用二进制编码（0/1）或整数编码。
1.1每个基因代表一种原料或一个工艺参数（如：温度、搅拌时间）。
1.2示例：染色体 [1, 0, 1, 1, 0] 代表在备选的 5 种原料中，选用了第 1、3、4 种，禁用了第 2、5 种。

2.遗传操作：通过选择（轮盘赌/锦标赛）、交叉（单点/多点基因交换）和变异（0/1翻转），不断组合尝试新的“原料菜单”。

三、 内层：线性规划（LP）逻辑 —— 决定“放多少”
1.条件接收：GA 传给 LP 当前保留的原料清单（所有编码为 1 的原料）。
2.数学建模与求解：
2.1目标函数：\(\min \text{Cost} = \sum (Price_i \times X_i)\) （其中 \(X_{i}\) 为第 \(i\) 种原料的百分比重量）。
2.2约束条件：\(\sum X_i = 100\%\)；以及各项营养成分的线性不等式。

3求解反馈：
3.1可行解：LP 秒级算出当前原料组合下，成本最低且营养 100% 合规的精确比例（\(X_1, X_3, X_4\) 的具体数值）。
3.2不可行解：若当前原料组合无论如何调整比例都无法凑齐目标营养（例如：选的全是低蛋白原料，却要求高蛋白成品），LP 直接报错。

四、 适应度评估（Fitness Evaluation）—— 决定“好不好”计算当前染色体的综合得分。
1.若 LP 求解失败：说明该原料组合不合法，直接赋予极低适应度，让其在下一代进化中被自然淘汰。
2.若 LP 求解成功：将 LP 算出的精确配比送入“风味/质构预测模型”计算感官得分。
3.综合适应度公式：\(\text{Fitness}=w_{1}\times (1/\text{最低成本})+w_{2}\times \text{预测口感得分}-w_{3}\times \text{工艺惩罚项}\)
（\(w\) 为权重系数，根据项目是“成本导向”还是“品质导向”进行调整）

五、 终止与输出（Termination）当算法达到设定的最大迭代次数，或连续多代适应度不再提升时，算法停止，并输出：
1.最佳原料组合（GA 的最佳染色体）。
2.黄金量化配比（该组合下由 LP 算出的各原料精准克数）。
3.预计各项指标（成本、营养成分、预测口感得分）。
